# キャラの声づくり

声を作る・直す前に、必ず `Docs/Voice/Irodori-Direction-Rules.md` を全部読み、その決まりに従う。加藤さんの感想から分かったこと（読み方・イントネーション・朗読のトーン・こもりの原因・候補の好み）はすべてそこにある。

新しい試しは `Docs/Voice/jobs/<名前>.json` を書いて `Tools/Irodori-Make.py` で作る（試しのたびにスクリプトを書かない）。

要点（詳しくは上の文書）：
1. 声に渡す文は漢字かな交じり。かなにするのは、文書の「読み違えた語の一覧」にある語と、新しく読み違いが分かった語だけ。
2. 説明（キャプション）には、声だけでなく場面・相手・気持ちを書く。打ち消し（「〜は無い」）は書かない。朗読は話すときより声を低く落とす。
3. 見本（--ref-wav）にはこもりの無い音だけを使う（`Tools/Irodori-Hinata9.py`の`muffled`で0.5秒ごとに確かめる）。
4. 1行につき2〜3通り作り、こもり・読み違いを機械で外してから人が耳で選ぶ。書き起こしでは高低（アクセント）の誤りは分からない。
5. ElevenLabsの無料枠で作ったひなたの声は、公開・配布・動画に使わない。実在の声優・人物の声に似せない。

新しく分かったこと（加藤さんの指摘、読み違い、良かった設定）は、その都度 `Docs/Voice/Irodori-Direction-Rules.md` に書き足してコミットする。そうすればClaude・Codexのどちらが次に作業しても同じ決まりで作れる。
