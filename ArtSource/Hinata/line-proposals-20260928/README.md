# ひなた：アニメ／萌え寄りの線画比較案

2026-09-28、ユーザーから「既存の顔を残す案は却下」「教科書寄りの絵から、もっとアニメ／萌えへ」「線画の案を複数先に」と指示されたため制作。

- A-anime-sd.png：元気な王道アニメSD。高めのツインテール、笑顔、カーディガンとスカート。
- B-office-oneesan.png：落ち着いた表情、低めのツインテール、パンツのオフィスカジュアル。
- C-compact-sd.png：低頭身で顔と表情を目立たせる方向。短めで大きな髪束、丸首とカーディガン。

3案とも内蔵画像生成で線画のみ作成。人間の手描き原画ではない。
既存の顔の画像は流用していない。各生成指示はA/B/C-prompt.txtに保存。
白背景の線画であり透過素材ではない。塗り・表情差分・ゲーム内採用はまだ行っていない。
色・影は採用方向を決めた後、Ink Workshopの素材別の塗りと編集可能なマスクで制作する。
小さいUIではCが顔を大きく見せやすい。A/Bは200px表示に合わせて髪や衣装の内側の線を整理する余地がある。
細部の指・首・髪の接続と、塗りのための線の閉じ方は、採用案を決めてから局所修正する。今回の画像は完成素材とは扱わない。

旧衣装差し替え案と先の教科書寄り線画は承認済みの基準にしない。
