# ひなたの声・試聴用台本

AI StudioのGemini 3.8 Flash TTSから比較用WAVを9案保存。A/B/CはAutonoe、D以降はLeda。ユーザーはD・Gを良いと評価し、H再生後も舌足らずの方向を評価。Iの評価はまだ確認していない。ゲームへの登録は0件。未評価のテイクの聴き比べ結果を捏造しない。

共通の短い台詞と反応を、同じ声候補で演技だけ変えて比較する。その後に声質を変える。人物の違いと演技の違いを最初から混ぜない。

- A：元気な同僚。普段使いの第一候補。声量は普通、語尾は明るい。成功時だけ弾ませる。
- B：アニメ寄り。軽快で表情のある元気。ただし幼児声や常時の甲高い叫びにはしない。
- C：頼れる元気。張りのある声、歯切れよく前向き。警告・失敗では声量を下げて一緒に考える。
- D：高音・あどけない元気系アニメ声。ユーザーが「結構良い」と評価し、基準案として保存。ファイルを上書きしない。ゲーム採用の最終決定ではない。
- E：さらに高音・甘め。基準より高い音域を指示。
- F：少し舌足らず。語を変えず、聞き取れる範囲で子音を丸くする演技。
- G：鈴のように澄んだ声。ユーザーが良いと評価した基準案。声質の比喩であり、鈴のSEは足さない。
- H：さらに高音＋舌足らず＋強いアニメ的抑揚。
- I：鈴のような声＋強いアニメ的抑揚。

`a-natural.txt` / `b-anime.txt` / `c-confident.txt` がStyle用の指示。`lines.txt` が読み上げ本文。

音源ごとに前後の無音、読み間違い、指示文の混入、耳障りな高音、声の一貫性を試聴でチェック。声が決まるまではUnityの既存枠を空のままにする。WAVは画面に生成された実音声であり、模擬電子音ではない。全ファイルのRIFFサイズと実際の保存サイズを照合。制作画面はアカウント情報が含まれるため追跡しないArtifactsへ保存する。
AI Studioの無料枠は制限あり。有料プランへの変更・APIキーの作成・他人の声の複製を試聴のために勝手に行わない。

## 保存と再生

ルートのWAVはStudioの生成原音を保存したもの。録音のし直し・ピッチ加工・速度変更はしていない。各原音は上書きせず残す。
Studio出力でByteRateが96000だが、実データは24kHz/mono/16bit（48000byte/sec）。`prepare-listening.cjs`は原音を変更せず、ヘッダーのByteRateだけを正しくした再生用コピーを`listening/`へ作る。PCM音声データの一致とRIFFサイズを確認する。試聴にはこのコピーを使う。
保存WAVのローカル再生は生成要求ではない。ゲームはAPIを呼ばないので、何回再生しても生成枠を使わない。各比較ファイルは連続10台詞で、個別リアクションとしてそのまま登録しない。
