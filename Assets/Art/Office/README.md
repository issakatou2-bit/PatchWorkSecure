# オフィス背景

`office-day.png` は、この改修で組み込み画像生成ツールから作成したオリジナル背景。
UIを画像に焼き込まず、Unityの操作部品を前面に重ねる。ユーザー指定のひなた画像の代替ではない。
初回取り込みは `SceneBuilder.Office.cs` が行う。

## 生成プロンプト

Create one production-ready environment background illustration for a Japanese indie cybersecurity office-management game, PatchWorkSecure. Landscape 1536x1024. An inviting lived-in small Japanese company office, isometric elevated three-quarter cutaway diorama, polished crisp pixel-art-inspired game environment with careful block shapes, pastel mint and teal, warm peach, ivory desks and golden afternoon sunlight, subtle navy outlines. Main subject entire office centered with desks, monitors, chairs, printer, glass meeting room, server cabinet, plants and windows; a few very small anonymous employee sprites quietly working. Mood: a peaceful ordinary workday worth protecting, not a dystopian hacking bunker. Space around the diorama edges in warm pale cream. Beautiful handcrafted tycoon game feel, strong coherent lighting, rich readable small details but clear silhouettes. This is ONLY an environment art asset behind real interactive UI, not a screenshot or UI mockup. NO interface panels, NO HUD, NO lettering, NO text, NO logos, NO border, NO watermark. No large foreground character or anime portrait. Opaque background.
