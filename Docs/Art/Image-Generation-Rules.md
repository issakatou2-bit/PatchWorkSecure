# 絵づくりの決まり（ChatGPTの画像生成、Claude、2026-10-03）

10/1〜10/3に加藤さんの確認で分かったことをまとめる。絵を作る・直すときは、まずこれを読む。経緯は各フォルダのREADME。

## 1. 手順

1. 内蔵ブラウザでChatGPTを開く。同じ絵柄を続けるときは、同じ会話の続きで頼む（「Generate anime character sheet」＝3頭身と二人絵3、「Create Office Illustration」＝二人絵1・2、「Create Rival Silhouettes Sheet」＝強敵）。
2. 基準の絵をそろえる：ライブラリの「＋」→「スペースのファイルを追加」から、集合絵「春色オフィスと三人の華やかな笑顔」、秘書「夕暮れの秘密を囁く秘書」、ひなた「ポーズいろいろ、ピンク髪ちび少女」を添える。**ライブラリの他のファイル（加藤さんの別の資料）は使わない。**
3. 保存：`touch "$CLAUDE_SCRATCH/dl-marker"`→画像を開いて右上の保存ボタン→`sh Tools/Take-ChatGPTDownload.sh <保存先.png>`。
4. 保存した絵は必ず自分で開いて、2章の点検をしてから見せる。直しは「ここだけ直して、ほかは同じ」と、変える所を1つずつ書く。
5. フォルダのREADMEに、ファイル名・中身・採用か不採用か・理由を書いてコミットする。ゲームに入れるときは`Docs/Reference-Asset-Provenance.md`にも書く。

## 2. 点検（見せる前に必ず）

- **手と指**：5本ずつか。指さす先が正しいか（画面を指すはずが人の胸を指していた）。腕が長すぎないか（伸ばした腕が人の前を横切った）。
- **持ち物の矛盾**：ノートのリングが1か所だけか（2か所に付いていた）、腕時計を「その時計を指す手」に付けていないか。
- **頭身と輪郭**：3頭身の絵は3人とも約2.5頭身・太い茶色の輪郭（ひなたに合わせる。エンジニアは3回目でやっとそろった）。
- **表情の強さ**：りりぃ（エンジニア）は控えめ。でも見れば分かる（小さなドヤ顔、小さな驚き、目を細めた笑み、たまにむすっ）。
- **関係**：3人は同じ会社の対等な同僚。上下関係に見える構図にしない。
- **文字**：絵の中に読める文字・数字・ロゴを入れない（暗号の0と1、ランダムな英数字のように「読めなくてよい記号」は例外）。
- **似せない**：他の作品のキャラ・デザイン・実在の人に似せない。

## 3. 強敵（擬人化）

- 設計と10大脅威との対応は`Docs/Rivals-Persona-Design-2026-10-03.md`。脅威＝キャラ、攻撃手法＝技。
- 人ではなく「手口の化身」。実在の職業の人（委託先の作業員、取引先の社員、社員）を悪者に見せない。「借り物」「偽物」と分かる形にする。
- ひと目で手口が分かる道具を、**意味の正しいもの**から選ぶ（例：ランサムウェアは鍵・暗号の円盤・暗号文。ハッシュ・ソルトは別物なので混ぜない）。
- 絵柄の基準：`ArtSource/Rivals-20261002/persona-ransom-3.png`（クリプタ）。かわいいが脅威がある、全年齢、性的にしない。顔は小さくかわいく描き、人ではない印（鍵穴の瞳など）を残す。
