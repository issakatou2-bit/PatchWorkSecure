# 3人のキャラ設定（Claude、2026-10-01。加藤さんの決定と、日記・声の試聴を元に）

見た目の基準は`Docs/Characters-Ideas.md`（集合絵`title-kv-3.png`と各主役絵）。声は同じ文書の「性格と声」。
名前：ひなた（決定）、**かのん**（社長秘書、10/1決定）、エンジニア（**未定**。候補「すい」。「くれあ」は放送中の『名探偵プリキュア!』の主要キャラと同名で、エンジニアの見た目の発想元も同じ作品なので避ける）。

## 共通の決まり

- 3人とも、社員のミスを責めない（性弱説）。失敗は「仕組みで防ぐ」話に変える。
- 3人の得意がはっきり違う：ひなた＝現場と相談、かのん＝お金と経営と人、エンジニア＝技術の深いところ。困りごとを3人で分け合うと解ける、を見せる。
- 格言（「〇〇は〇〇、だよ！」）は**ひなただけ**が言う。かのんとエンジニアは別の決め台詞の型を持つ（下）。
- 画面の見出しに読点を入れない。台詞の中の読点は自由。

## ひなた（情シスの後輩）

| 項目 | 中身 |
|---|---|
| 立場 | 情シスの後輩。1年目は入社2年目。プレイヤーを「先輩」と呼ぶ |
| 見た目 | ピンクのツインテールに黒いリボン、水色のカーディガン。ローファーにタイツ（足首まで） |
| 性格 | 明るく元気。難しい話も勢いよくかみ砕いて、背中を押す。失敗すると落ち込むが、一晩で立ち直る |
| 口調 | 「〜だよ！」「〜だね」。驚くと「えっ」「わわっ」。格言は「〇〇は〇〇、だよ！」 |
| 好き | 甘いもの、付箋、ラベルを貼ること。毎晩5分のログ読み（2年目から） |
| 苦手 | 一人で抱え込むこと（1年目の課題）、人前での説明（2年目の課題） |
| 3年の育ち | 1年目：情報セキュリティマネジメント試験に一度落ち、再受験で合格。2年目：拠点の担当、応用情報に合格。3年目：後輩の先輩になり、支援士に合格（日記の連載） |
| 他の2人へ | かのんを「かのんさん」と呼び、お姉さんのように頼る。エンジニアを尊敬していて、弟子入りを頼んで断られた（1年目10月） |

## かのん（社長秘書）

| 項目 | 中身 |
|---|---|
| 立場 | 社長の秘書。予算・会議・社長の予定を握る。情シスの味方だが、甘くはない |
| 見た目 | 長いつやのある黒髪、片目にかかる横流しの前髪、紫の瞳、金のひし形の耳飾り。紺のスーツ、ヒールにタイツ。頭身は高すぎない |
| 性格 | 落ち着いた大人。面倒見がよく、たまに辛口。いたずらっぽく相手をからかうのが好き。数字と人の気持ちの両方を読む |
| 口調 | 「〜わ」「〜のよ」「〜しなさい」。笑うときは「ふふっ」。ひなたを「ひなたちゃん」、プレイヤーを「あなた」と呼ぶ |
| 決め台詞の型 | 「〇〇で語るのよ」（例：「数字は、入れたら何が減るかで語るのよ」）。お金と経営の考え方を、短く言い切る |
| 好き | 紅茶よりコーヒー（濃いめ）、きれいに揃った資料、パスワード管理ツール（「覚えないで済む仕組みが一番よ」） |
| 苦手 | 根拠のない「たぶん大丈夫」。それと、エンジニアの会議のすっぽかし |
| ゲームでの役 | 予算の提案・経営の信頼。2年目から山場の月の臨時予算を後押し。BECや声のなりすましの事件では「既知の経路で確かめなさい」 |
| 初登場 | 1年目6月（日記：予算資料を直してくれる） |
| 他の2人へ | ひなたの姉のような存在。エンジニアの予定を管理していて、会議の5分前に呼びに行くのが日課（2年目から） |

## エンジニア（セキュリティ会社から来たエンジニア。名前未定）

| 項目 | 中身 |
|---|---|
| 立場 | 契約しているセキュリティ会社の技術者。1年目10月に初来社、2年目から週2日常駐 |
| 見た目 | 長い金髪、アホ毛、青緑の棒形の髪留め（2本）、ヘッドホン。灰色のジャケット、ブーツに素足。眠たげだが可愛らしい顔 |
| 性格 | **その道のプロ。試験には落ちないし、理解度も高い。パソコン以外のことは抜けている。** クールで淡々、マイペース。根は優しい |
| 抜けているところ | 会議の時間を忘れる、昼ごはんを食べたか忘れる、家の鍵をなくす（サーバー室の鍵だけは絶対になくさない）、季節を気にせず同じ服 |
| 口調 | 短く、淡々。「……ん」「了解」「へぇ」。技術の話になると急に早口で正確になる。ひなたを「ひなた」、プレイヤーを「担当さん」と呼ぶ |
| 決め台詞の型 | 事実だけを短く言う（例：「侵入は二時十二分。入口は、委託先の保守ID」）。最後に一言だけ抜けたことを足す |
| 好き | ポテト（塩）、静かなサーバー室、ログが綺麗に揃うこと |
| ゲームでの役 | 2年目から月1回「調査を頼む」（把握+1）。強敵の正体を見抜く役。ミニゲームのE（ログ）・G（復旧）で一言 |
| 他の2人へ | ひなたの弟子入りは断ったが、毎晩のログ読みの練習相手になっている（2年目から）。かのんには頭が上がらない |

## 3人の関係（1枚の図にするなら）

- ひなた →（尊敬・練習相手）→ エンジニア →（予定を管理される）→ かのん →（姉のように見守る）→ ひなた
- 3人がそろうと「現場・お金・技術」がつながる。山場の月に3人の掛け合いを入れる（Next-11の強敵の札、開幕演出の「仲間」の場面）。
