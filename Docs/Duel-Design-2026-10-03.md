## 0. 手本の開き方

- `Docs/Mockups/proto-h-duel.html`をブラウザで開く。最初は相手を選ぶ画面。
- 場面を直接出す（撮影・比較用）：ファイルのURLの後ろに`#shot=○○`を付ける。末尾に`-2`〜`-10`を付けると、その順の相手（`-1`か省略でクリプタ）。

| `#shot=` | 出る場面 |
|---|---|
| `select` | 相手を選ぶ（10人。最高評価の札の見本つき） |
| `prep` | 対戦の準備（はじめて。技・糸口・弱点・持っていく備えを2つ選んだところ） |
| `prep-hard` | 対戦の準備（腕だめし。糸口と弱点が隠れている） |
| `duel` | 対戦の1ターン目（技の予告と手札） |
| `hidden` | 腕だめしの1ターン目（糸口が「？」） |
| `block` | 合う備えで受け止めた瞬間 |
| `hit` | 合わない備えで受けて、被害か停止が増えた瞬間 |
| `win` | 勝ち（4回受け止め、1回見送り。評価A） |
| `lose` | 負け（合う備えを持たずに押し切られる） |

例：`proto-h-duel.html#shot=duel-9`（フラッダの対戦）、`#shot=win-10`（スプーフィに勝ち）。撮影のときは音を鳴らさず、評価をブラウザに保存しない。
- 操作：手札の数字キー`1`〜`3`で受ける、`C`で相談、`X`で見送る（マウスでも同じ）。
- 「今日の一問」：日付を種にして相手と技の順番が決まる（腕だめし）。同じ日なら誰でも同じ問題。
- 最高評価はそのブラウザの`localStorage`（`protoH-best`）だけに残る。

## 1. 遊び方

1. **相手を選ぶ**：10大脅威の子10人から1人。
2. **準備**：相手の技（3〜4個）と、それぞれの**攻撃の糸口**を見て、**持っていく備えを3つ**選ぶ。候補は「基本の備え」6つ（糸口と1対1）と、その子の弱点のうち基本以外の「重ねる備え」。
   - はじめて：技の糸口と、その子の弱点が見える。
   - 腕だめし：糸口と弱点が隠れる。技の名前と説明（解説書の要約）から糸口を考える。
3. **対戦（5ターン）**：毎ターン、相手が技を予告する（台詞・技の名前・糸口・外れたら増えるゲージ）。手札（持ってきた基本の備え）から1枚で受ける。
   - 技の糸口に合う備え → **受け止めた**（旧版のパリィの考え方）。連続で受け止めると、ひなたの連鎖の声の字幕（いいね！→その調子！→すごい！…、Next-21で決まった7段階）が出る。
   - 合わない備え・見送り・時間切れ → 被害か停止のゲージが増える。ひなたは責めずに「この技の糸口は○○。次は△△で受けよう」と言う。
   - **ひなたに相談**（1回、減点なし）：糸口と対策の基本を教えてくれる。腕だめしでは糸口が見えるようになり、制限時間が5秒のびる（相談文化をゲームの得として見せる）。
   - 5ターン目は**本気の技**（外れたときの増え方が大きい）。
4. **結果**：勝ちなら相手の**負け台詞**と**効いた備え**、負けなら相手の**勝ち台詞**と「次は、これを持っていこう」。どちらでも、全ターンの振り返り表（技・糸口・選んだ備え・結果・**受け止められた備えと対策の基本**）と、その子の弱点の一覧を必ず見せる（性弱説：負けても学びにする）。

## 2. 勝ち負けの決まり（ゲーム用の数値。現実の被害の大きさではない）

| 項目 | 値 | 置き場所（手本） |
|---|---|---|
| ターン数 | 5（すべての技を最低1回。足りない分はくり返し。順番はランダム） | `TURNS` |
| 持っていく備え | 3つ | `SLOTS` |
| 外れたときの増え方 | 40、本気の技は60 | `HIT`・`FINAL` |
| 重ねる備え（その子の弱点を持っている） | 1つにつき増え方−15、最大−30、最低10 | `LAYER`・`LAYER_MAX`・`MINHIT` |
| 負け | 被害か停止のどちらかが100以上 | `LIMIT` |
| 制限時間（1ターン） | はじめて15秒、腕だめし10秒。切り替えでなしにもできる | `TIME` |
| 評価（勝ちのとき） | 受け止め5＝S、4＝A、2〜3＝B、0〜1＝C | `finish()` |

- **どちらのゲージが増えるか**：糸口が「マルウェアの利用」「データの暗号化」の技と、DDoS（フラッダ）の技は**停止（業務）**。それ以外は**被害（情報・お金）**。ゲーム用の整理で、現実の被害の種類を言い切るものではない。
- **重ねる備え**は、その子の弱点（`OpsThreatCatalog`の`weaknesses`）に入っている備えを持っていると効く。基本の備え（例：クリプタに対する分離バックアップ）も弱点に入っていれば重ねて効く。弱点に入っていない備えは重ねても効かない扱いにはせず、**候補に出さない**（「この備えはこの脅威に効かない」と誤って覚えさせないため）。
- 準備で合う備えを3つ選べば、はじめてでは必ずSが取れる（覚えるための練習）。腕だめしと今日の一問は、技の説明から糸口を読み取る力を試す。
- 相談は減点しない。見送りも選べる（無理に選ばなくてよい）。

## 4. 学べること

- **技（手口）→攻撃の糸口→対策の基本**のつながり。解説書の表1.2の考え方そのもので、10大脅威のどの項目にも同じ6つの糸口が使われることを、対戦をくり返して覚える。
- 一つの脅威にも、いくつもの糸口がある（クリプタは暗号化だけでなく、脆弱性からの侵入や、暗号化しない脅しもある）。一つの備えだけでは足りない。
- 合う備えがないときも、弱点の備えを重ねれば被害を抑えられる（多層防御）。「必ず防げる」ではなく「抑えられる」。
- 相談は得（相談しても減点しない。答えを教えてもらえる）。負けても、どこで受け止められたかが分かれば次は強くなれる。
