## 3. Steamでの評価の予測

- **今のまま出した場合：好評率60〜70%（「賛否両論」〜「やや好評」）の見込み。** かわいさ・UI・学びは褒められ、短さ・簡単さ・単調さが低評価の理由になる。価格が千円を超えると「短い」の声が強まる。
- **下の改善を入れた場合：80〜90%（「非常に好評」）を狙える。** 同じ規模のインディーの育成・経営ゲームでは、長さと周回要素、キャラの掛け合いが評価を大きく左右する。
- 予想される好評の声：「ひなたがかわいい」「UIがきれい」「セキュリティの勉強になる」「演出が気持ちいい」
- 予想される不満の声：「1時間で終わる」「簡単すぎる」「限定対応ばかり選ぶ」「周回する理由がない」「会話が少ない」

## 4. 改善の優先順位（面白さ・完成度）

1. **判断を迷えるものにする（最重要）**：状況によって最善の方針が変わるようにする。例：バックアップがある月は「復旧を急ぐ」が得、兆候を調べていない月は「広く止める」が安全、繁忙期は停止の損失が大きい。目標は「迷える選択肢の平均」2.0以上、限定の比率60%以下。
2. **緊張と失敗**：難易度の段階（やさしい／ふつう／むずかしい）。放置した兆候が翌月に大きな事件へ育つ連鎖。
3. **長さと周回**：3年のキャンペーン（年ごとに新しい仕組みと出来事）、攻撃手口図鑑、キャラ3人の選択（得意分野が違う）。
4. **会話イベントと社員の個性**：社員3人とひなたの短い会話イベント、選択肢つき。
5. **オフィスが育つ**：設備・年数に応じて部屋の見た目が変わる。
6. **声の組み込み**（`Docs/Voice/Integration.md`）。

## 5. すぐ直せるUIの不具合（Codex向け）

- タイトルのボタンをモック通りに：ニューゲームはピンクのグラデーション＋光、他は白（今は灰色・えんじ色）。
- 吹き出しの名札「ひなた」が、枠の上端で切れている（タイトル・依頼書ほか）。名札を枠の外に出し、切れないようにする。
- 依頼書の報酬の見出し「題材・根拠」「社員の声」が、別の報酬カードの上に乗っている。見出しを消すか、正しい位置へ。
- 月報の依頼名の改行（「使っているライブラ／リが対象？」）。読点・語の切れ目で改行する。
- 臨時予算+1万円は、報酬として実感しにくい。判断の深さの改善と合わせて、額か報酬の種類を見直す（Verify系で検証）。
