# 画面の変化と手応え — 演出方針と実装状況

ユーザーの指摘：ゲームらしくなってきたが、同じ構図と数値の更新が中心で絵面が単調。良い結果／悪い結果、効果音・BGM、数値の変化をもっと実感したい。
既存の簡易音、ステータス差分の色・パンチ、短い通知、結果のアクセントはある。以下はそれらの存在を否定する説明ではなく、まだ弱い世界とのつながりを補う案。

## 優先する変化

- 設備導入：関連設備の起動、改善の段階、支払額と能力の増分を同じ場所で見せる。
- 社員の支援：実際に助けた社員に短い動作・作業アイコン、加算値を表示。未実装の仕事や助力を演出だけで偽らない。
- 対応開始：症状のある対象の印と警戒音。未確認を「侵害確定」と表現しない。
- 被害・停止：該当設備の停止表示、損失・停止時間の短い差分、鈍い音。全画面の赤点滅を連打しない。
- 復旧・成果：設備が戻る、社員が安心する、効果・成長の数値が順に加算される。
- 山場の突破・年度達成：通常より大きい短い祝福。初回は見せ、反復時は短縮できる。

## 数字とゲージ

関連する項目のそばに符号と単位のある差分を出し、短くカウント／ゲージを動かす。
金額減は必ずしも失敗ではない。購入の支払と損失を別の音・表示にする。疲労の増加は悪化、休息による減少は回復。増減の符号だけで成功色・警告色を決めない。
最終値とラベルはすぐ読めるようにする。アニメーションが終わるまで操作を待たせない。数値は実データから取り、派手に見せるための架空の加算は作らない。

## 音と世界観

通常業務・警戒・対応・月報でBGMの密度とテンポを変え、切り替えは短いクロスフェード。
クリックは控えめ、成長は上向き、被害は低い鈍音、警告は短く識別できる音。ボイスと重要な警告が重なる場合は優先度で整理。
普段は0.2〜1秒程度の動作をオフィス内へ。四半期・年度末だけ短い場面演出を挟み、毎操作のカットインや毎月の長いムービーにはしない。
消音でも変化が分かり、動きを減らす設定と長い演出の短縮を守る。

## 9/28の実装

- 対応画面をオフィスと3案の比較へ整理。被害・停止・対応費を単位付きで揃え、詳しい根拠は別画面へ。未確認を侵害確定と表示しない。
- 6項目の確定値は即時表示したまま、直前の増減だけを短く浮かせる。購入等の予算支出は青、疲労減少は緑、被害による支出・悪化は赤。操作は遮らず、動きを減らす設定では位置とスケールを動かさない。
- 設備購入は関連するオフィスの印が反応し、実際の導入名・Lvを約1.5秒表示。
- 月報のオフィスに、確定した被害・停止の小さな記録と、実際に加算された社員支援を表示。現在も障害が続くと誤解させない。支援0で活躍を捏造しない。
- 36反応の字幕・表情・音声接続。音源未投入は設定で明示。

設備の絵自体の変化、NPCの作業アニメーション、四半期の場面演出、BGM楽曲、実声のボイスは未実装。実際の楽しさは人間の試遊で確認する。
