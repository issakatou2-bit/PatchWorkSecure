# ひなた — 最終手描き素材の方針

ユーザー要望: 「生成ではなく手描きが望ましい。生成絵は暫定なら可。オフィスなのに学生服は違う」。

## 現在の暫定素材

`Assets/Sprites/Hinata/hinata_normal.png` は、生成された顔・髪を残し、チェック柄を切り抜き、仕事着をベクターで描き足した素材。
**人間の作画による最終イラストではない。手描き化が完了したとは扱わない。**
修正後は本物のアルファ透過。首下は `Tools/Hinata-workwear.svg` で編集可能。
表情素材が無い場面ではこの通常絵へフォールバックし、以前の図形キャラに戻らない。

## 最新の方向（9/28の再指定）

「服以外の雰囲気はまず良い」は、その後の回答で更新された。
**旧顔のAIらしさが問題なので、顔・身体・衣装を一体で根本から作り直す。**
ピンク／オレンジ系の髪とデフォルメ感は保つが、旧顔の画素を保持することは条件ではない。
線画生成＋素材別に指定する着彩をユーザーが希望。人間の手描きとは区別する。
最初に作った低いツインテールの線画は「かわいいが教科書チック」と評価された。これを基準にせず、もっとアニメ／萌え系へ。
**まず線画を複数比較し、決めてから塗る。先に着彩や6表情の量産を進めない。**
比較案は `ArtSource/Hinata/line-proposals-20260928/` のA/B/C。3案は未着彩・未採用。
後の評価は「どれもかわいいがAI感が残る」。どれも承認された原画ではない。
ユーザーは外注の提案ではなく、こちら側の創意工夫による改善を求めている。外注を標準方針や必須条件にしない。
追加の局所パーツ置換 `ArtSource/Hinata/face-study-20260928/` も「絵心ない」と不評。不採用として保存し、ゲームに投入しない。Ink Workshopは編集道具であり、美術品質を保証するものではない。コードで目を単純化する方式をこのまま反復しない。

## 最終作画の方向

- 役割は社会人の情シスパートナー。学生・アイドルの制服表現は避ける。
- 添付 `preview.webp` 左下のピンク髪の子を、髪型と親しみやすいデフォルメの参考にする。
- 2〜2.5頭身。少ない色数、太めの輪郭、控えめなハイライト。小さく表示しても目と口が読めること。
- 9/28の回答：顔・髪・全体の雰囲気は保ちたい。AIらしさを減らし、かわいい職場向けの衣装、表情とポーズの両方の差分が欲しい。
- 白のブラウス、小ぶりな襟、くすみローズ／落ち着いた色のカーディガン、紺の膝丈Aラインまたはパンツ、フラットな靴、小さな社員証。黄ばみ・金縁・大きな制服リボンを避ける。
- 現在の顔の艶と、首下の均一な図形線が一致していない。衣装変更だけでは解決しない。最終原画は頭と身体を同じ線・塗りの方針で作画する。小さい表示で輪郭と目・口が読めることを優先。
- 胸の大きい制服リボン、短いプリーツスカート、学生向けの制服ラインは使わない。
- 失敗時もプレイヤーを責めず、一緒に次の備えを考える表情にする。

## 差分と納品仕様

同じキャンバス、頭・足・視線の位置を揃えた透過PNGを、1表情1ファイルで用意する。
目安1024×1024、身体を切らない余白。実ゲームでは約200pxの高さで表示する。

| ファイル名 | 場面 |
|---|---|
| hinata_normal.png | 通常の会話 |
| hinata_proud.png | 対策が成功して喜ぶ |
| hinata_worried.png | 疲労や予算を気にかける |
| hinata_alert.png | 攻撃を知らせる |
| hinata_relieved.png | ぎりぎり防げて安心する |
| hinata_sad.png | 失敗を受け止め、立て直す |

表情だけでなく、通常は端末を持って案内、成功は小さなガッツポーズ、考え中は顎に手、警告は端末を示す、安心は肩の力を抜く、失敗は次の手順を一緒に確認する動作を検討する。警告前に攻撃や犯人を確定する台詞・表情にはしない。
差分を別々に生成して顔・体格・衣装を変えない。まず通常の全身原画を確定し、同じ原画から表情／手／腕の差分を作る。6種の完成素材はまだない。
