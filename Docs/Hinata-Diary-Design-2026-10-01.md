# ひなたの日記（Claude、2026-10-01。加藤さんの案「ボイスつきの日記で、ひなたが別で試行錯誤している生きてる感」）

ねらい：ひなたは画面の案内役だけでなく、プレイヤー（先輩）の横で、自分でも悩み、失敗し、育っている。それが日記で伝わる。
作品の芯（人のためのセキュリティ、性弱説、ミスを責めない）を、ひなた自身の失敗と立ち直りで見せる。

## 1. いつ・どこに出るか

- **月報のあと**に1ページ（読まずに閉じてもよい。右上に「日記が書かれた」の印）。
- **年度の終わり**は長めの1ページ（年度替わり・挑戦の終わりの画面の前）。
- **タイトル**に「ひなたの日記帳」。読んだページを後から読み返せる（図鑑と同じく、集める楽しみ）。

## 2. 1ページの中身（3つの層）

| 層 | 中身 | 作り方 | 声 |
|---|---|---|---|
| ① 今月の出来事 | 「今月はメールの詐欺。森さんが別の電話で確かめてくれた」 | ゲームの記録から自動（事件・選んだ対応・結果・活躍した社員・ミニゲームの評価） | なし（字幕） |
| ② ひなたの所感 | 結果で書き分け。良い月は得意げ、悪い月は落ち込みつつ前を向く。止めすぎの月は「次は確かめてから」 | 型（良い／普通／悪い／止めすぎ／正常だった）×題材の分類で用意した文から選ぶ | なし |
| ③ ひなたの連載 | プレイヤーとは別の、ひなた自身の3年間の物語（下の36話） | 固定の文 | **最初の1〜2文を声で**読み上げ、続きは字幕 |

- 連載は年・月で決まる（挑戦の結果では変わらない）。同じ挑戦をくり返すと同じ話になるので、**読んだページは短く畳んで出し**、「つづきを読む」で開く。最終話だけは、届いた結末（途中で終了／A・S／SS）で3通り。
- 途中で挑戦が終わったら、そこまでの連載が日記帳に残る。先の話は次の挑戦で読める（続きを見たい、が再挑戦の理由になる）。

## 3. 登場人物の呼び方

ひなた＝情シスの後輩（1年目は入社2年目）。プレイヤー＝「先輩」。社長秘書＝「秘書さん」、セキュリティ会社のエンジニア＝「エンジニアさん」（名前は未定。決まったら置き換える）。社員は今の名前（森・大野・相田・小川・佐伯）。

## 4. 連載36話の筋書き（10/1改訂：情シス・インフラ・ネットワークの現場の中身と「あるある」を入れた）

加藤さんの追加の希望：**かなりリアルな内容とあるある**。連載の本文に現場で本当に起きること（作業の手順、原因の見つけ方、失敗の型）を入れ、ページの余白に「情シスあるある」を1行ずつ書く。
書き方の決まり：①実在の手順・用語は正確に（必要なら一言の説明を添える）②社員や利用者を笑いものにしない（性弱説。「何もしてないのに」は本人も本当に心当たりがない、という目線）③ひなた自身の失敗は隠さず書く。

試験の時期は実際に合わせる（2026-10時点のIPAの公表）：情報セキュリティマネジメント試験は通年のCBT（会場のPCで、いつでも受けられる）。応用情報技術者試験・情報処理安全確保支援士試験も**2026年度からCBT**になり、前期は11月ごろ・後期は2月ごろの期間内に会場で受ける。本文では年や日付を書かず「会場で受けてきた」「結果が届いた」と書き、制度が変わっても古くならないようにする。

### 1年目「ひとりで抱えない」— 先輩に追いつきたい。情報セキュリティマネジメント試験に挑む。

| 月 | 話（本文の中身） | 声で読む冒頭 | 余白の「情シスあるある」 |
|---|---|---|---|
| 4月 | 夜に一人で復元を試したら、戻す先を本番のフォルダにしかけて冷や汗。先輩に「復元は、まず別の場所へ」と教わる | 「こっそり復元を試したら、本番に上書きしかけた……」 | 「バックアップあります」と「戻せます」は、別の話 |
| 5月 | 新入社員のPCを20台、初期設定（キッティング）。1台ずつ手作業で、名前の付け間違いが2台。モニターにパスワードの付箋を見つけ、言い方に悩む | 「新人さんのPC、20台セットアップした！……付箋、見つけちゃった」 | 4月は、PCとアカウントとお問い合わせが一度に来る |
| 6月 | 秘書さん初登場。予算の資料を直してもらう。「“入れたら何が減るか”で語るのよ。止まる時間、失う売上」 | 「社長の秘書さんに、予算の書き方を教わったよ！」 | 何も起きなかった年ほど、「その予算いる？」と言われる |
| 7月 | 「ネットが遅い」の原因は、会議室のハブにLANケーブルが輪っかにつながっていたこと（ループ）。抜いたら全部直った | 「ネットが遅い原因、会議室のケーブルが輪っかになってたの」 | 「ネットが遅い」の正体は、だいたいWi-FiかDNSかケーブル |
| 8月 | 夏休み中に、サイトの証明書の期限が切れて警告が出た。期限を誰の予定表にも入れていなかった。休み明けに全部の期限を一覧にする | 「休み中に、証明書の期限が切れちゃってた……」 | 証明書の期限は、担当者がいなくなった年に切れる |
| 9月 | 試験の勉強を始める。「更新はすぐ全台に」ではなく、まず数台で試す理由（業務ソフトが動かなくなることがある）が分かった | 「試験の勉強、はじめました！　過去問、むずかしい……」 | 更新のあと再起動しない人、だいたい忙しいだけ |
| 10月 | エンジニアさん初来社。ポテトを食べながら、ログの中の総当たり（同じ所からの何十回ものログイン失敗）を一瞬で見つける。弟子入りを頼んで断られる | 「セキュリティ会社のエンジニアさん、すごかった。ポテト食べてたけど」 | 夜中のアラートは、8割が誤報。でも残りの2割のために起きる |
| 11月 | 共有フォルダの権限の棚卸し。台帳（Excel）と実際の設定が合わない。おかしな設定を見つけたら、設定したのは去年の自分だった | 「権限の棚卸しで、変な設定を見つけた。……設定したの、わたしだった」 | 台帳のExcelは、更新した人しか信じていない |
| 12月 | 年末の大掃除で、サーバー室のケーブルに全部ラベルを貼った。その日、3人が相談に来てくれた | 「サーバー室のケーブルに、ぜんぶラベル貼ったよ！」 | 年末は「来年でいいや」の相談が、全部年内に来る |
| 1月 | 試験に落ちた。悔しくて帰り道で泣いた。エンジニアさんは「試験は一回で受かったけど、会議は三回すっぽかした。……得意と苦手は、人それぞれ」と言ってくれた（エンジニアさんは試験に落ちない。パソコン以外が抜けている） | 「……試験、だめだった」 | 再起動で直ると、ほっとするけど、ちょっと不安 |
| 2月 | 毎晩5分、ログを読む練習を始める。「いつも」を知らないと「いつもと違う」は分からない、とエンジニアさん | 「毎晩5分、ログを読むことにしたよ。続けられるかな」 | 「何もしてないのに壊れた」は、本人も本当に心当たりがない。だから記録が大事 |
| 3月 | 手順書の第1版ができた。先輩から付箋だらけで戻ってきた。いちばん大きな付箋は「元に戻す手順がない」 | 「手順書、できた！……付箋だらけで戻ってきたけど」 | 手順書は、書いた本人がいちばん読まない |

### 2年目「広がる会社」— 再受験で合格。新しい拠点を任され、人に教える難しさを知る。

| 月 | 話（本文の中身） | 声で読む冒頭 | 余白の「情シスあるある」 |
|---|---|---|---|
| 4月 | 2月の再受験で合格していた！ 新しい拠点の担当に。拠点のルーターの管理パスワードが、出荷時のままだった | 「受かってたーっ！……拠点のルーター、パスワードが初期のままだった」 | 機器の管理画面のパスワード、箱に書いてある |
| 5月 | 在宅の人が増えて「VPNがつながらない」の問い合わせが倍に。半分は家のWi-Fiだった。よくある質問の一覧を作る | 「VPNがつながらない問い合わせ、半分は家のWi-Fiだった」 | 「画面が真っ黒です」の半分は、電源が入っていない。もう半分は、本当に大変 |
| 6月 | 秘書さんとAIの使い方の決まりを作る。「全部禁止すると、みんな隠れて使うわ。使っていい道を作るの」 | 「秘書さんと、AIのルールを考えたよ」 | 禁止すると、隠れて使われる |
| 7月 | クラウドへの引っ越しの夜。名前の切り替え（DNS）は、前の日に「覚えておく時間」（TTL）を短くしておく、とエンジニアさんに教わる。二人で朝までやった | 「DNSの切り替え、前の日にTTLを短くしておくの、覚えた！」 | 「ちょっとした変更」は、金曜の夕方にやらない |
| 8月 | 拠点で講習会。「パスワード付きのZIPはなぜだめ？」に、うまく答えられなかった（パスワードを同じメールの経路で送ると、一緒に盗まれる）。準備ノートを作る | 「講習会、質問にちゃんと答えられなかった。悔しい」 | 説明会でいちばん鋭い質問は、いちばん後ろの席から来る |
| 9月 | 応用情報の勉強。毎晩のログ読みのおかげで、午後の問題の図が読めるようになってきた | 「毎晩のログ読み、役に立ってる気がする！」 | 「とりあえず全部管理者権限で」は、あとで必ず困る |
| 10月 | 熱を出して休んだ。でも、手順書とよくある質問のおかげで、みんなで回してくれた | 「休んじゃった。でも、会社はちゃんと回ってた」 | 担当者が休んだ日に、その担当のシステムが止まる |
| 11月 | 応用情報を、試験会場のパソコンで受けてきた（CBT）。手応えは、半分くらい | 「試験、終わった……。半分くらい、できたかな」 | 試験の日に限って、会社から電話が来る |

| 1月 | 応用情報の結果が届いた。合格。秘書さんがケーキを買ってきた | 「合格してた！　秘書さんがケーキ買ってきてくれたの」 | 年度末の駆け込みのライセンス購入、毎年ある |
| 2月 | 手順書を他の人に試してもらったら「どこを押すのか分からない」。画面の写真と、「なぜこうするか」を書き足す | 「手順書、分かりにくいって言われちゃった。書き直し！」 | 「たぶん大丈夫」は、大丈夫じゃない |

### 3年目「狙われる会社」— 後輩を育て、情報処理安全確保支援士に挑む。

| 月 | 話（本文の中身） | 声で読む冒頭 | 余白の「情シスあるある」 |
|---|---|---|---|
| 4月 | 後輩が来た。最初に伝えたのは「分からないときは、すぐ聞いていい」。自分が先輩に言われたこと | 「後輩ちゃんが来たよ。わたし、先輩になっちゃった」 | 新人さんの「すみません」は、だいたい謝らなくていいこと |
| 5月 | 後輩が怪しいメールのリンクを押して、すぐ報告に来た。端末をネットから外して調べたら、被害なし。責めずに「すぐ言ってくれてありがとう」と言えた | 「後輩ちゃん、すぐ報告してくれた。ちゃんと、ありがとうって言えたよ」 | 報告が早い職場は、事故が小さい |
| 6月 | 大きな山場。エンジニアさんに「判断が早くなったね」と言われる。止める範囲を、台帳を見てすぐ決められた | 「エンジニアさんに、判断が早くなったって言われた！」 | 「全部止めて」は簡単。「ここだけ止める」が仕事 |
| 7月 | 支援士の勉強。午後の問題は、長い事例の文章を読んで答える。夜が短い | 「支援士の午後問題、長い……夜が足りない」 | 夏はサーバー室の空調が、いちばん大事な設備 |
| 8月 | 3人で夏祭り。秘書さんの浴衣。仕事の話を一回もしない日 | 「今日は3人でお祭り。仕事の話、一回もしなかった」 | 休みの日に通知を切れるようになったら、一人前 |
| 9月 | 取引先のセキュリティ確認の質問票、200問。3年前なら半分も答えられなかった。台帳と手順書があったから、全部に根拠つきで答えられた | 「監査の質問、全部答えられたの。3年前のわたしに見せたい」 | 質問票の「はい」には、全部根拠を聞かれる |
| 10月 | 後輩が初めて一人で障害に対応できた。まず影響の範囲を確かめて、次に元に戻す手順を確認してから作業していた | 「後輩ちゃんが、ひとりで直せたの！」 | 「切り戻し手順あります」の一言で、夜が平和になる |
| 11月 | 支援士を、試験会場のパソコンで受けてきた（CBT）。終わってから、少しだけ泣いた | 「試験、終わった。ちょっとだけ、泣いちゃった」 | 「一時的な設定」は、3年後も残っている |
| 12月 | 結果待ちの年末。3年分の日記を読み返す。最初のページの字がぐちゃぐちゃ | 「最初の日記、読み返したら、字がぐちゃぐちゃだった」 | 3年前の自分の設定に、助けられる日もある |
| 1月 | 支援士の結果が届いた。合格。最初に先輩に伝えた | 「合格だって。最初に、先輩に言いたかったの」 | 合格しても、問い合わせの電話は鳴る |
| 2月 | 先輩への手紙のような日記。教わったことを、全部書き出す | 「先輩。いつもありがとう、って、ここに書いておくね」 | 情シスの仕事は、うまくいくほど誰にも気づかれない |
| 3月（結末で3通り） | SS：何も起きない朝が、いちばん嬉しい。／A・S：守り抜いた。次の目標を見つけた。／途中で終了：それでも、明日も会社は続く。もう一回 | SS「なにごともない朝って、こんなに嬉しいんだね」／A・S「3年間、守り抜いたよ。次は、何を目指そうかな」／途中「ここで終わりじゃないよ。明日も、会社は続くから」 | 「なにごともない」は、だれかが毎日つくっている |

- 声：冒頭36行＋結末の分岐2行＝38行（台本`Docs/Voice/hinata-script-v2.csv`の`diary_*`）。余白のあるある36行は字幕だけ。
