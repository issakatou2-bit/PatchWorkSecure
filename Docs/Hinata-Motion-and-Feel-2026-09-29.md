基準は`Mockups/Hinata-Motion.md`の①②と`Game-Feel-Research-2026-09-29.md`の◎。第1工程の置き換えは`bf45f12`でコミット済み。ゲームのルール・報酬・難易度・セーブの内容は変えない。

## ひなた

- 新試作と旧版の全身絵に、足元を固定した呼吸（縦1〜1.015倍、2.8秒）と上下動（6px、3.2秒）を付ける。文字送り中は上下動を1.5倍、周期を半分にする。
- ポーズ交換は0.9倍→絵を交換→1.06倍→1倍。喜びは予備動作・36pxの跳躍・着地・土ぼこり、驚きは12px後退と短い震え、悪い結果は10px沈んで揺れを半分にする。
- 画面が変わったときだけ0.35秒で入場（行き過ぎ約12px）、0.2秒で退場。同じ月の行動や購入では入場・退場・画面ワイプを繰り返さない。ポーズの反応とボタンの手応えは残す。
- 紺の輪郭の「!」・汗・キラキラ・怒り・もやもや・土ぼこりを独自図形で制作。元のキャラクター原画は描き直さない。
- `pose_fists`の基本・半目・閉眼・閉口を、そのままUnityへ取り込む。目と口の範囲を別のマスクで重ね、閉眼と閉口も同時に表示する。髪・体・足は差し替えない。
- まばたきは3〜5秒間隔、半目→閉眼→半目を合計0.15秒、20%で2回続ける（3回以上には連鎖しない）。口は文字送り中だけ0.08〜0.12秒で開／閉を切り替え、句読点と待機時は閉じる。
- 現在あるのは**基本ポーズの差分だけ**。他の17ポーズは今の1枚絵で動く。口の「中」素材は無いので2段階。声の音量に連動する入口はあるが、ボイスの実ファイルはまだ投入していない。
- 新試作の「動きを減らす」は移動・拡縮・回転を止める。まばたきと差分交換・透明度の変化は残す。旧版にはこの設定画面を新設していない。

## ◎の9技法

| 技法 | 今回の反映 |
|---|---|
| ヒットストップ | 備えの発動・判子の瞬間、演出用の時計だけ0.08秒停止。`Time.timeScale`とボタン・判定は止めない |
| 繰り返しの短縮・スキップ | 発動の流れは初回3.2秒、2回目以降2.3秒（設定ONは1.15秒）。既存のスキップも維持。カード・判子の出現も2回目から短縮 |
| 対象の部屋へのズーム | 事件画面の左の地図を、全景から確認対象の部屋へ0.4秒で寄せる。方針ボタンはその間も選べる。侵害確定とは表示しない |
| 集中線 | 発動カットインの中に、枠で切った集中線。省演出では回転を止める |
| 遅れて減るゲージ | 予算・業務の安定の減少を白い残像で0.2秒残し、0.4秒で縮める。直前の実数値だけを使い、予算に架空の上限を設けない |
| 数え上げ・刻み音・止まりの拡大 | 承認済みB案の刻み音を使用。数値が確定したら短くフェード停止し、最後に1.1倍の小さな拡大。省演出では拡大しない |
| あと1つ | 社内依頼は実際の設備／現場の達成条件、成長目標は設備の組合せ／相談文化の条件から表示。達成後は消す。目標名の幅を縮めない |
| SEの音程差 | 操作・結果・刻み音・判子等に±5%。演出専用の乱数で、イベント抽選やゲームの乱数を消費しない |
| BGMを下げる | カットイン・声の間に55%へ滑らかに下げ、その後0.3秒で戻す。消音・音量設定を維持 |

◎以外の「育つオフィス」「複数年」「図鑑」「環境音」等は追加していない。新しいSE候補も勝手に登録していない。
