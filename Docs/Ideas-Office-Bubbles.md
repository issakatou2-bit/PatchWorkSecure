# 案：オフィスの「困りごとの泡」（2026-09-29、加藤さんの発案。未承認）

プリンタの紙詰まり、PCが重い、パスワードを忘れた、などの小さな困りごとを、オフィスの部屋の上に**泡**として浮かべる。
押すと弾けて解決し、小さな報酬が入る。数%でレア演出・レア報酬。

## ねらい

- 月の計画画面は「読んで選ぶ」だけで、手で触る気持ちよさが少ない。泡は**1回の操作で結果が出る**小さな手応えになる。
- 「なにごともない日常をツギハギしながら守る」というテーマそのもの。情シスの仕事の大半は小さな困りごとだと、遊びながら伝わる。
- 画面に動きが出る（泡の出現・揺れ・弾け・報酬の数字が飛ぶ）。季節演出や部屋の見た目とも合う。

## 既存の仕組みとの関係

- 既存の**日常チケット**（月1件、1工数、共同対応か委任）は「少し考える仕事」。泡は**0工数でその場で終わる仕事**。重ねず、2段にする。
- 泡は部屋ごとに出る（`Docs/Mockups/Next-Screens.md`の⑤マップの部屋割り）。導入した改善が泡の種類と数を変える。例：資産管理を入れるとPCトラブルの泡が減り、代わりに良い知らせの泡が出る。

## ルール案（数値はVerify系で詰める）

| 項目 | 案 |
|---|---|
| 出る数 | 月3〜5個。計画画面の部屋の上に、時間差で浮かぶ |
| 操作 | 押すと弾ける。工数は使わない。月末（計画の確定）で残った泡は消える。罰則なし（性弱説） |
| 通常の報酬 | 信頼+1、相談文化+1、疲労-1のどれか（小さく。改善投資の判断を崩さない） |
| 相談の泡（1〜2割） | 「このメール大丈夫？」「USBを拾った」など。弾くと**兆候が1つ分かる**。これが事件の対応を選ぶ手がかりになる（判断の深さとつなぐ。下記） |
| レア（約3%） | 金色の泡。社員のお礼カード、図鑑の1枠、ひなたの特別セリフ・声、社員の経験+1 |

- レアの中身は、**見た目・図鑑・キャラの反応を中心にする**。大きな数値の得にはしない（運で年度の結果が決まらないように。教育ゲームとしての誠実さ）。
- レアの確率を隠さない（設定か図鑑に「たまに出る」と書く）。有料の要素ではないので、ガチャ的な煽りはしない。

## 判断の深さとのつなぎ（本命）

泡を「気持ちいいだけのクリック」で終わらせない。
- 相談の泡を弾くと、今月の兆候（例：不審なログインが増えている、バックアップが先週失敗していた）が分かる。
- 兆候が分かっているかどうかで、事件のときに最善の対応が変わるようにする（例：バックアップが無事と分かっていれば「復旧を急ぐ」が得、何も分かっていなければ「広く止める」が安全）。
- つまり**泡＝情報集め**。弾いた泡が事件の判断に効く、という手応えが「限定一択」を崩す材料になる。詳細は判断の深さの設計（Claude担当）で詰める。

## 演出

- 出現：ふわっと浮かび、小さく揺れる。部屋のアイコン（プリンタ、PC、鍵、封筒）が泡の中に見える。
- 弾け：縮んでから弾ける、しずくが散る、報酬の数字が上へ飛ぶ、軽いSE（B-brightの系統）。
- 連続で弾くと音程が少しずつ上がる（3個目以降）。
- レア：金色の縁、弾けたときに星が散って小さなカットイン。ひなたの専用の声。
- 自動化：社員Lv.が上がると、一部の泡をその社員が自動で弾いてくれる（成長の実感。日常委任と同じ考え方）。
