# 事件画面の承認モック移行

## 範囲

`Docs/Mockups/Next-Screens.md`と4枚のHTMLを先にコミット（`a2a8f7b`）。今回は①の選択・発動画面を実装し、独立した④の季節演出も追加した。②依頼書・報酬、③新タイトル・共通遷移、⑤マップの操作、⑥ランクの恩恵はまだ実装していない。報酬・難易度の数値は変更していない。

## 見た目と操作

- 選択画面：暗い赤の背景、動く黄紺の警告帯、震える緊急札、拡大した現場、未確認の黄色札、備え一覧、白い3枚のカード。名前・対応費・被害／停止の帯・決定ボタンを分けた。
- 1600×900基準：左の現場は24,120／600×770、右は648,120／928×770、カード間隔16。ひなたは現場内−40,470／360×360、吹き出しは250,560／320幅。
- 詳細は対応アイコン、黄色の未確認札、ひなたの吹き出しから開く。既存の知識・対応力の内訳・社員育成を消していない。予算欄から記録・設定を開ける。
- 発動画面：対応の流れ、斜めのピンク帯、設備／社員の発動、光・粒、未導入設備の仮定比較、揺れる針、確定値、整備なしとの比較。
- 発動は約5秒。初回は最後まで、2回目からは画面のスキップボタンで月報へ。多数の発動は直近3行を送り、各発動を1回ずつ見せる。全件の内訳は月報にも残る。
- 動きを減らす設定では位置・回転・跳ね・針の移動を止める。発動の名称、内訳、確定値は消さない。
- 設備と社員に別の短い合成SEを追加した。発動中は事件用BGM、月報へ進むと通常BGMへ戻す。ひなたの新しい絵・ボイスは投入していない。

## 表示の根拠

- 対応前の「備えが効く」は、公開情報の`Estimate`と、その設備を外した公開見積もりを比較する。未確認の深刻度・正常操作の抽選結果を使って札を変えない。
- 発動した設備は既存の`investmentEffects`で、被害か停止時間の実際の削減があるものだけ。各設備の値は一つずつ外した比較なので足し合わせない。
- 社員支援は確定結果の`power.staff`。正常操作だった場合に、攻撃へ支援したというカットインを出さない。
- 未導入設備は、同じ事件・対応・成長前の状態でLv.1を仮定して比較する。前提設備が揃うもの、実際に被害／停止が減るものだけを記録する。購入・工数・報酬・経験は発生しない。
- `OpsState.Resolve`は一度だけ精算・保存する。針・演出・スキップは乱数を使わず、月報や過去の結果も書き換えない。旧記録の新しい比較項目はnullのまま許容する。
