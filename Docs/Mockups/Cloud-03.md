## 照らし合わせる資料（一次資料を優先）

- IPA「情報セキュリティ10大脅威 2026」解説書［組織編］（`https://www.ipa.go.jp/security/10threats/10threats2026.html`からPDF）。PDFの文字が読めなければ`pip install pypdf`で読む。読めなければ「未確認」と書く。
- IPA「中小企業の情報セキュリティ対策ガイドライン」、IPAの試験の案内（応用情報・支援士のCBT・科目の名前）、JPCERT/CC、NISCなどの公的な資料。
- ネットにつながらない・開けない資料は「未確認」と書く。推測で「正しい」にしない。

## 見る点（`Docs/Fact-Check-2026-10-02.md`の1章の決まり）

用語の意味、手順の順番、数字・年・制度の名前、言い過ぎ（「必ず」「絶対」）、実在の会社・製品・国・IPアドレス・ドメインを悪く見せていないか、人を責める書き方になっていないか（性弱説）。

## 作るもの

`Docs/Fact-Check-Sweep-2026-10-03.md`（新しいファイル）：
- 調べた範囲と件数（どのファイルの何件を見たか）。
- 「明らかな誤り」「言い過ぎ・誤解されやすい」「古い情報」「要相談（好み・解釈）」に分けた表：場所（ファイルとid）、今の文、直す案、理由、出典（URLとページ）、確認した日。
- 声のある行（ひなた・かのん・りりぃ）は、そう分かるように印を付ける（直すと声の作り直しが要るため）。
- 最後に、Codex向けの指示書の下書き（直す案のうち「明らかな誤り」だけを、文だけの変更として並べたもの）。
