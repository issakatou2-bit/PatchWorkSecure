# クラウドの作業の順番待ち（Cloud-Queue）

旧アカウントのクラウドセッションは、加藤さんに「**次の作業**」と言われたら、この表の上から順に、状態が「未着手」の最初の1つを実行する。

## 「次の作業」と言われたら

1. `git fetch origin` で、元のブランチ`feature/title-quiz-ending-flow`の最新を取り込む（PCのClaudeが新しい指示書を足していることがあるため。自分の作業用ブランチに`origin/feature/title-quiz-ending-flow`を取り込んでから始める）。
2. この表を読み、状態が「未着手」の最初の1つの指示書を読んで実行する。決まりはどの指示書も`Docs/Mockups/Cloud-01.md`の0章と同じ。
3. 始めたら、この表の状態を「作業中（日付）」に、終わったら「済（日付・PRの番号）」に書き換えてコミットする（この表だけは書き換えてよい）。
4. 1つ終わるごとに、加藤さんに日本語で短く報告する：何を作ったか、PRの番号、決めてほしいこと、次の「未着手」は何か。
5. 「未着手」が無くなったら、そう報告して止まる（自分で新しい作業を始めない）。
