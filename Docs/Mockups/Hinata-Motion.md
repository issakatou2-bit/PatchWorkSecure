## ① 1枚絵のまま動かす

| 動き | いつ | 仕様 |
|---|---|---|
| 呼吸 | 常時（待機中） | 縦だけ1.0→1.015倍、2.8秒周期のサイン波。足元を基準点にする（Pivot＝下端中央） |
| ゆっくり上下 | 常時 | 上下6px、3.2秒周期。呼吸と周期をずらし、機械的に見せない |
| 差分の切り替え | 表情・ポーズが変わる瞬間 | 0.9倍に縮む（0.06秒）→1.06倍（0.08秒）→1.0倍（0.1秒）。縮んだ瞬間に絵を差し替える |
| 跳ねる（喜び） | 成功・ランクアップ・発動 | 予備動作：縦0.92・横1.06（0.08秒）→跳ぶ：縦1.08・横0.95で上へ36px（0.18秒）→着地：縦0.94・横1.05（0.06秒）→戻る。着地で小さな土ぼこり |
| 驚いて身を引く | 事件の発生・警告 | 後ろへ12px・3°傾く（0.1秒）→小刻みに左右2px×4回（0.25秒）→戻る |
| しょんぼり | 悪い結果 | 下へ10px沈み、縦0.97倍で止まる（0.4秒）。上下の揺れを半分にする |
| 話している間 | 吹き出しの文字送り中 | 上下の揺れを1.5倍・周期を半分に（はずむ話し方） |
| 登場 | 画面に入るとき | 画面外から横に滑り込み、12px行き過ぎて戻る（0.35秒、イーズアウトバック） |
| 退場 | 画面から出るとき | 0.2秒で横に抜ける（登場より速く） |

感情マーク（頭の横に出す小さな図形。絵文字は使わない）：

| 汗のしずく | 心配・パニック | 頭の横から下へ20px流れて消える |
| 音符・キラキラ | 喜び | 上へ漂いながら2〜3個、0.8秒 |
| 怒りマーク | ふくれっ面 | 2回小さく脈打つ |
| もやもや | 考える・呆れ | 頭上に小さく回る |

## ② まばたき・口パク

**9/29：基本ポーズ（`pose_fists`）の差分を用意済み**（`ArtSource/Hinata/gen-20260929/final/`、共通キャンバス496×615）。

| ファイル | 中身 |
|---|---|
| `pose_fists.png` | 基本（目を開けて口を開けた笑顔）。**差し替えに合わせて、この絵も新しくした** |
| `pose_fists_eyes_half.png` | 半目 |
| `pose_fists_eyes_closed.png` | 目を閉じる |
| `pose_fists_mouth_closed.png` | 口を閉じた笑顔（口パクの「閉」） |

- 4枚は同じ絵の上で**目と口の範囲だけ**を差し替えてある（`Tools/Make-FaceFrames.py`：瞳と口の濃い赤から顔の範囲を見つけ、位置を合わせて重ねる）。髪・体は完全に同じなので、切り替えても揺れない。
- 仕組みは「ポーズIDごとに、差分があれば使い、無ければ1枚のまま」。ほかのポーズ・表情の差分は、同じ方法で順次追加する（ClaudeがChatGPTの同じ会話で生成）。
- まばたき：開→半→閉→半→開。口パク：開（基本）↔閉を交互に。
- まばたき：3〜5秒に1回のランダム。開→半→閉→半→開を合計0.15秒。たまに2回続ける（2割）。
- 口パク：文字送り中だけ、0.08〜0.12秒ごとに開→中→閉をランダムに。句読点で閉じる。声がある場合は声の音量に合わせる。

## 確認

- ポーズや表情を切り替えても足元がずれないこと、動きを減らす設定で止まること、1年の通しプレイで演出が操作を待たせないこと（2回目以降の短縮）。
