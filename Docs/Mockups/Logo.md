# ロゴとアイコン — 実装指示（2026-09-29）

見本：`logo.html`、配置は`title-screen.html`ほか各モック。コンセプトは「ツギハギの当て布でできた盾」（題名のPatchWork＝つぎはぎしながら会社を守る）。

## 素材（`Assets/Art/UI/Logo/`、透過PNG）

- `wordmark.png`（1040×400）：「PatchWork」＋リボン「SECURE」。タイトル・年間評価・ロード画面に使う。
- `icon.png`（512×512）：アプリアイコン兼、画面内の小さな印。
- 原本はSVGをHTMLに書いたもの（`ArtSource/Logo/*.html`）。Edgeのヘッドレス表示で透過PNGに書き出している（`--default-background-color=00000000`）。書体はM PLUS Rounded 1c（OFL）。

## 配置

| 画面 | 置き方 |
|---|---|
| タイトル | 左上に大きなロゴ（幅640）＋左下にアイコン（132、-8°傾ける）。その下に「情シスの一年」と副題の帯。最初に弾んで出る |
| 計画画面 | 上部バーの一番左にアイコン（76） |
| 事件画面 | 上部バーの一番左にアイコン（68） |
| 依頼書・設定 | 見出しの帯の左にアイコン（44〜54） |
| 月報 | 見出しの左にアイコン（80） |
| 年間評価 | 右上に小さいロゴ（幅300、2°傾ける） |

## Player Settings（Steam向け）

- Default Icon：`icon.png`。Product Nameは「PatchWork Secure 情シスの一年」を仮とし、加藤さんに確認する。
- ロゴとアイコンの最終採用は、加藤さんがゲーム画面で見て決める。
