# チュートリアル・月報・年間評価・設定、ひなたの動き、効果音 — 実装指示（2026-09-28）

`Next-Screens.md`と`UI-Kit.md`の後に着手する。見た目はモック（同フォルダのHTML）を正とし、部品は`UI-Kit.md`の標準を使う。
`tutorial.html`と`settings.html`は、背景にUnityの計画画面の撮影画像（`Artifacts/CompanyOps/42-compact-planning.png`、gitの管理外）を使っている。

## ① 最初の1か月のチュートリアル：`tutorial.html`

ニューゲームの4月だけ。**説明の窓を読ませるのではなく、実際に押させて覚えさせる。**

- 画面を暗くし、押すべき部品だけを穴あきで明るく残し、黄色い光で脈打たせる。指のアイコンが上下する。
- ひなたが大きく出て、吹き出しは1つ。上に「STEP 2 / 6」と題名、吹き出しに進捗の点。
- **光っている部品を押すと次へ進む**（「次へ」ボタンは置かない）。「説明を飛ばす」はいつでも押せる。
- 手順案（6段階）：1 上の数値（予算・工数・会社の力）を知る → 2 「調べる」を押す → 3 「話を聞く」で社内依頼を開く → 4 「設備を導入」を開いて1つ導入 → 5 「月を進める」 → 6 事件で方針を選び、備えの発動を見る。
- 2年目以降やニューゲームの2回目は出さない（設定から再表示できる）。

## ② 月報：`monthly-report.html`

- 左上に月のメダルと「今月のふりかえり」。
- 事件の結果：被害・業務停止・対応費を大きな数字で3枚。「備えなしなら11万円」「見積もり0〜17時間」を添える。「効いた備え」の帯。
- 今月の成長：ランクが上がった項目は、ランク文字が弾み「RANK UP E→D」の札と、恩恵のひと言（`Next-Screens.md`の⑥）。ほかの増減は札で並べる。
- 社内依頼：達成なら、ツギハギ模様の「達成」判子が押される（大きく出て縮みながら傾いて止まる）。報酬の札。
- 活躍した社員：顔マーク、Lv、何をしたか、抑制力。**支援が無かった月は「今月は支援なし」**（活躍を捏造しない）。
- ひなたのひと言は結果に合わせる。下に「記録を見る」「5月へ ▶」。

## ③ 年間評価：`annual-report.html`

一年の締めくくりなので、**全画面で一番華やかにする。**

- 背景は金とピンクの放射光がゆっくり回り、紙吹雪が落ちる。
- ランクの判子（ツギハギ模様）が大きく押され、年間得点は数え上げ。
- 12か月のマスが0.08秒ずつ順に点灯する：達成＝緑、山場突破＝金、被害大・停止長＝赤、無事＝灰。
- 「一番効いた備え（MVP）」「活躍した社員」「攻撃手口図鑑」「成長目標」。
- ひなたが跳ねて喜ぶ。ボタンは「一年を振り返る」「タイトルへ」「もう一年挑戦」（＝ニューゲーム）。

**新しく必要な集計**：備えごとの発動回数と軽減額の合計（MVP）、社員ごとの支援回数。
**攻撃手口図鑑は未実装の新機能**（出来事40件のうち、遭遇したものを記録して一覧で読める）。先に集計と表示枠だけを作り、図鑑画面は別の指示で作る。

## ④ 設定：`settings.html`

- 標準ウィンドウ（`UI-Kit.md`）。見出しは「SETTINGS 設定」。
- SOUND：BGM・効果音・ひなたの声の3本のスライダー（ピンクのゲージ＋白い丸のつまみ）。
- DISPLAY：文字の大きさ（小・標準・大の切り替え、見本の文字を表示）、字幕のオン・オフ。
- MOTION：動きを減らす、演出の短縮（2回目以降の割り込み演出を短くする）。
- 左下に小さく赤で「記録を消す…」（確認の窓を必ず出す）。「閉じる」。**変更はすぐ反映して保存する**（保存ボタンは置かない）。

## ⑤ ひなたのまばたき・口パク（素材が必要）

画面の仕組みは先に作ってよい。絵が無い間は、今の1枚のままで動作する（無理に顔を描き直さない。コードで顔を描く案は不採用）。

必要な素材（今の立ち絵と同じ大きさ・位置の透過PNG。**顔の部分だけの差し替え絵**でよい）：

| ファイル名 | 中身 |
|---|---|
| `hinata_eyes_half.png` | 目が半分閉じた顔 |
| `hinata_eyes_closed.png` | 目を閉じた顔 |
| `hinata_mouth_open.png` | 口を開けた顔 |
| `hinata_mouth_mid.png` | 口を少し開けた顔（任意） |

動き：まばたきは3〜5秒に1回ランダム（開→半→閉→半→開、合計0.15秒）。口パクはセリフの文字送りの間だけ、0.08〜0.12秒ごとに開閉。声がある場合は声の音量に合わせる。
表情の6種（`Docs/Hinata-Art-Brief.md`）が揃ったら、表情ごとに同じ差し替えを用意する。

## ⑥ 効果音の実素材化

今の10種は合成音。以下を実素材にする。**加藤さんは以前「フリー素材より生成音源がよい」と答えているので、BGMと同じく生成を第一候補にし、使う前に聞いてもらう。** 出典・ライセンスは`Docs/Reference-Asset-Provenance.md`へ記録する。

| 場面 | 音の方向 |
|---|---|
| ボタン（通常） | 短く軽い「ポッ」。何度聞いても疲れない |
| 主な操作の決定 | 少し明るい「キラン」 |
| 設備の導入 | レジやコインの「チャリン」＋小さな上向きの音 |
| ランクアップ | 上がっていく3音のジングル |
| 数値の数え上げ | 細かい「チチチ」、止まる瞬間に「ポン」 |
| 事件の発生 | 短い警報＋低い衝撃音 |
| 備えの発動（カットイン） | 「シャキーン」と盾の音。一番気持ちよく |
| 被害の確定 | 鈍く低い音（長くしない） |
| 判子 | 「ドン」と紙に押す音 |
| 年度クリア | 華やかなファンファーレ（3〜4秒） |
| 画面遷移 | 帯が横切る「シュッ」 |

音量のバランス：ボタン類は小さく、発動・判子・ファンファーレを大きく。同じ音が短い間に重なる場合は1つにまとめる。
