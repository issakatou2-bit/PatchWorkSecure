# 次の画面と遊びの改善 — 実装指示（2026-09-28）

計画画面（`README.md`）に続く指示。モックは同じフォルダのHTMLをブラウザで開けば、動きも含めて見られる。
見た目・部品・色・動きは`README.md`の計画画面と共通。**モックを正とする。**
加藤さんは方向性を承認済み（「いいですね、それら進めてください」）。細部は試遊で詰める。

実装の順番：①事件画面（2枚） ②依頼書 ③タイトル・画面遷移 ④季節演出 ⑤マップの部屋割り ⑥ステータスの恩恵。
④はほかと独立しているので並行してよい。②の報酬と⑥はルールの数値に触れるため、`Tools/Verify-*.ps1`で検証すること。

## ① 事件画面：`incident-choose.html` → `incident-resolve.html`

ゲームの芯として扱う。**4月に入れた備えが、事件で発動して自分を救う瞬間を最大の見せ場にする。**

### 対応を選ぶ（`incident-choose.html`）

- 平常時との落差で緊張感を出す。背景は暗い赤、上端に黄黒の警告テープが流れる。「緊急対応」の札は細かく震える。
- 左：該当する部屋（ランサムならサーバー室）をオフィスから拡大して表示。部屋の枠が赤く脈打ち、「!」が弾む。症状と「影響範囲は未確認」を小さい札で出す。ひなたは小刻みに震え、セリフは1つ。
- 右上：「未確認：正常な操作の可能性もある」の黄色い札（誠実さのため必須）。「あなたの備え」に、導入済みの設備（緑）・未導入（灰）・支援できる社員を並べる。
- 右：3方針のカード。アイコン、名前、ひと言、対応費、業務停止と被害の**幅をゲージの帯で表示**。決定ボタンはカードごとに大きく。
- 「備えが効く」の札：**導入済みの設備が実際にその方針で働く場合だけ**付ける（複数に付いてよい）。正解の目印ではなく事実の表示。費用や停止の不利はそのまま見せる。

### 備えが発動する（`incident-resolve.html`）

方針を決めたら、次の順で見せる（合計4〜6秒。2回目以降はクリックで飛ばせる。動きを減らす設定では、帯の出入りを止めて表示だけにする）。

1. 左の「対応の流れ」で、選んだ方針に✓が付く。
2. **カットイン**：ピンクの斜めの帯が左から入り「分離バックアップ 発動！」＋効果を1行。止まっている間に光と粒、専用の効果音。右へ抜ける。**実際に効果が出た設備・社員ごとに1回ずつ**、順番に出す。
3. 社員の支援も同じ流れに入れる（「佐伯の支援 抑制力+4」）。
4. **未導入で、あれば効いた設備**は点線の枠と「?」で「あれば、業務停止をさらに短くできた」と見せる。次の投資の動機になる。
5. **結果の針**：被害・業務停止の帯の上で針が左右に揺れ、確定値で止まる。結果は計算済みで、針は見せ方だけ（乱数を増やさない）。確定値は大きな数字で出す。
6. 「備えなしなら 被害11万円」の比較を添える（現行の「全整備Lv.0の場合との比較」を使う）。
7. ひなたが跳ねて喜ぶ（悪い結果なら、しょんぼりして揺れを小さくする）。

## ② 社内依頼の依頼書：`mission-brief.html`

「話を聞く」で開く。**今月限定のミッション**だと一目で分かるようにする。

- 上の帯：「社内依頼 4月」「期限：今月中」。
- 依頼人の丸アイコンとひと言、依頼の題名を大きく。
- 「どちらかの道で達成」：A 設備で示す／B 現場で確かめる。各項目をチェックボックスで表示し、済んだ項目に✓、進捗「1 / 2」。費用と工数を小さく添える。
- 「達成すると」：報酬をアイコン付きで並べる。
- ボタン：「閉じる」「引き受ける」。ひなたが、達成に近い道を具体的に教える。
- 月末に達成していれば、月報で依頼書に「達成」の判子を押す演出。

**報酬の変更（要検証）**：現在の報酬（信頼+3、年間+45点）では月の予算がほとんど変わらず、実感が無い（予算＝20＋信頼÷20）。
モックでは「臨時予算+5万円」と「ひなたの会話」を足している。臨時予算の額はVerify系でバランスを確認して決めること（易しくなりすぎるなら+3万円にする、道によって報酬を変える、など）。
「ひなたの会話」は依頼ごとに短い会話を1つ用意し、達成した月の月報で表示する。

## ③ タイトル画面と画面遷移：`title-screen.html`

- オフィスをくっきり表示し、ゆっくり拡大・移動させる。左側は白いグラデーションで文字を読みやすくする。桜が舞う（季節演出と共通）。
- ロゴ「情シスの一年」は大きく、白とピンクの二重の影。最初に弾むように出る。副題はピンクの斜めの帯。
- メニュー：ニューゲーム（ピンク、光が流れる）／つづきから（保存した月を表示。記録が無ければ灰色で押せない）／遊び方・設定。
- ひなたは大きく右側に。吹き出しは1つ。

画面遷移（全画面で共通にする）：

| 場面 | 演出 |
|---|---|
| 通常の画面切り替え | ピンクの斜めの帯が0.3秒で横切り、その裏で画面を入れ替える |
| 月替わり | 0.5秒の暗転 → カレンダーがめくれる → 「5月」を大きく＋季節のひと言（1秒） → 計画画面 |
| 事件の発生 | 画面が一瞬赤く光り、黄黒のテープと「緊急」の文字が0.8秒で割り込む → 事件画面 |
| 月報 | 結果に判子（達成・被害など）。社内依頼の達成もここ |
| 年度末 | 12か月のマスが順に点灯して一年を振り返り、最後にランクの判子 |

どれも2回目以降はクリックで短縮でき、動きを減らす設定を守ること。

## ⑤ マップの部屋割り（表示と操作のみ）

現状は改善11種に対して印が3つしかなく、「相談できる現場」の印が倉庫に置かれている。部屋ごとに役割を決め、マップを遊ぶ場所にする。

| 部屋 | 担当する改善・要素 |
|---|---|
| サーバー室 | 分離バックアップ・冗長化・更新運用・監視・ネットワーク分離 |
| 執務室 | 多要素認証・資産台帳、社員の相談（「?」） |
| 会議室 | 教育・訓練・手順・自動化 |
| 受付 | 社外（取引先・来客・詐欺メール）に関する出来事 |

- 部屋を押すと、その部屋の改善項目の一覧が開く（導入もそこから）。
- 導入すると部屋の見た目が変わる：ランプの点灯、小物の追加など、Lvに応じて段階的に。
- 出来事は該当する部屋で起きる（事件画面の拡大もその部屋）。
- 社員の顔マークは、手伝っている部屋へ移動する。

## ⑥ ステータスの恩恵（要検証）

現状、各ステータスの効果は小さく、プレイヤーに見えない。

- 経営の信頼：0→100で月の予算が+5万円だけ
- 相談文化：詐欺・漏えい系の事件でのみ抑制力に加算
- 疲労：事件の圧力が最大+6

**ランクごとに、目に見える恩恵を付ける**（ウマ娘のスキルに近い）。案：

| ステータス | 恩恵の例 |
|---|---|
| 相談文化 C以上 | 社員が兆候を報告し、事件の前月にオフィスへ「?」が出て予告される |
| 相談文化 B以上 | 事件の見積もりの幅が狭くなる |
| 経営の信頼 C以上 | 追加予算の提案が通りやすくなる |
| 経営の信頼 B以上 | 四半期ごとに臨時予算のイベント |
| チームの余力 E以下 | 「うっかりミス」の出来事が起きやすくなる |

- ランクが上がった瞬間に「相談文化 E→D！ 社員が相談に来やすくなった」と帯とバッジで演出する。
- ステータスを押すと「今の効果」「次のランクで得られるもの」を表示する。
- 行動を選んだら、光の粒がボタンから該当ステータスへ飛び、ゲージが伸びる（原因と結果を目で追える）。

## 守ること

`README.md`の「守ること」と同じ。特に：予測と確定の区別、架空の数値を作らない、未確認を侵害確定に見せない、動きを減らす設定。
