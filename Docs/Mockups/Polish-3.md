## 月報（`OpsGame.Reports.cs`）

1. 社内依頼の報酬の下に「ひなたの会話」という文字だけが浮いている。何かのボタンの名残なら消すか、押せるボタンの見た目（UIキットの小ボタン）にする。
2. 「効いた備え」が無い月に「被害 −0万円 / 停止 −0時間」が出る。0のときは数字の列を出さず、「次に効きそうな備え」を1つ（`potentialInvestmentEffects`の先頭）点線の枠で見せる。
3. 大きなひなたの立ち絵がある画面では、吹き出しの中の小さな顔アイコンを出さない（重複）。
4. 「活躍した社員」が空の月は、枠が大きく空く。社員3人の顔を薄く並べ、「次の月は支援を頼める」と1行添える。

## 計画画面（`OpsGame.Planning.cs`、`OpsGame.OfficeFeedback.cs`）

5. サーバー室・会議室にある「未導入」の点線の枠が、半透明の青い四角の列に見え、表示の乱れに見える。枠は白い点線の角丸＋小さな鍵か「+」の印にし、数を部屋ごとに最大3つまでにする。
6. ひなたの吹き出しの改行が語の途中（「強／くなったよ！」）。月報で直した改行の処理を、吹き出しにも使う。
7. マップ左下、ひなたの頭の後ろに灰色の半円（印の一部）が見えている。ひなたの立ち絵より後ろの印は、ひなたと重なる位置に置かない。
