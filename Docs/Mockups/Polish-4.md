# 画面の仕上げ 4 — 細部の監査（Claude、2026-09-29）

加藤さんの方針：**細部で妥協しない**（泡が半透明にならず、べた塗りの円になっていた件がきっかけ）。
モックとUnityの撮影を並べた比較（`Tools/Compare-Mock.py`）で見つけた差。どれも表示だけで、数値・ルールは変えない。

## 今後の決まり（毎回）

- 見た目を変えたら、**`py -3 Tools/Compare-Mock.py <モックHTML> <撮影PNG> <出力PNG>` でモックと並べた画像を作り、差を1つずつ確かめてから完了とする**。「だいたい同じ」で終えない。
- 半透明・光沢・グラデーション・影・傾きなど、Unityの標準部品で再現しにくい質感は、**UI画像（`Assets/Art/UI/`）で描く**。単色の`Image`で代用しない。

## 計画画面（手本 `planning-bubbles.html`、撮影 `133-bubbles-*`）

1. **泡がべた塗りの円になっている**。モックはガラス玉（中心が明るく、縁が白、下の地図が透ける、外側に色の縁と影）。素材を用意した：`Assets/Art/UI/Bubbles/bubble-normal.png`（青）、`bubble-consult.png`（ピンク）、`bubble-rare.png`（金）、`bubble-rare-ring.png`（金の点線の輪。ゆっくり回す）。200×200、直径140の泡＋影の余白。中のアイコンは今のまま上に重ねる。作り方は`ArtSource/UI/bubbles.html`。
2. 泡の揺れ（ゆっくり上下左右に漂う）と、出現時の拡大して弾む動きが、モックどおりか確かめる。
3. 「サーバー室」の名札に、ランプの点滅（緑・緑・黄の点）が重なっている。点滅は名札の外（部屋の中の機器の上）へ移す。
4. 未導入の「＋」の点線の枠が、部屋ごとに固まって並び、ノイズに見える（Polish-3の5で最大3つにしたが、まだ目立つ）。枠の線をもっと細く薄く（白・不透明度50%）、部屋の隅に寄せる。
5. 「業務時間」の札が、マップ上端の「困りごと n / 4」の横で、マップの枠をはみ出している。困りごとの札の右に、同じ高さで収める。
6. ひなたの名札「ひなた」が、マップの工具の印（灰色の丸）と重なる。吹き出しの近くにある印は、少し上へずらす。

## 事件画面（手本 `incident-choose.html`、撮影 `132-depth-incident*`）

7. 見出しの「ランサム攻撃」の札が、右端で薄い灰色になりほとんど読めない。モックどおり、題名のすぐ右にピンクの札で。
8. 「未確認：正常な操作の可能性もある」の札の文字が、黄色の地に白で読みにくい。文字を紺に。

10. 対応カードの数字と単位（「11 万円」「0〜17 時間」）の間が空きすぎ。モックどおり、単位を数字の直後に小さく詰める。
