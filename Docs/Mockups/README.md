## ゲームのデータとの対応

- **ランク文字**：S 95以上／A 80以上／B 65以上／C 50以上／D 35以上／E 20以上／F 10以上／G 10未満。色はA＝ピンク、B＝オレンジ、C＝ミント、D＝水色、E＝紫、F・G＝灰。「総合」は6項目の平均から出す。
- **チームの余力** ＝ 100 − 疲労。**表示だけの言い換えで、ルールは変えない**。調子：70以上「好調」、40以上「ふつう」、40未満「要休息」。
- 行動5つ＝現行の「現状を調べる」「社員と話す」「業務の優先度を確認」「当番を調整し休息」と「改善計画」タブ。効果の1行は、現行ボタンの効果表示を短くしたもの。
- 社員の顔マーク＝その行動を実際に支援できる社員だけに出す（`OpsGame.Team`の支援判定）。支援が無い行動には出さない（活躍を捏造しない）。
- 「話を聞く」＝今月の相談の詳細（ニュース・根拠・社内依頼はここに入れる）。「月を進める」＝現行の「今月の運用へ進む」。
- 山場の月：現行カレンダーで赤い下線が付いている月（6・9・12・3月）。
- オフィス上の印：相談が来ている部屋に「!」、困っている社員に「?」、未整備の設備に灰色の工具マーク、整備済みは緑のランプ。**文字ラベルは常時表示せず、カーソルを乗せたときだけ出す**。

## モックに無い情報の置き場所

日常チケット・運用ノート・運用チーム詳細・成長目標の詳細・社内事情・遊び方は、メニューボタンか、該当する部品を押したときの詳細画面へ移す。消すのではなく、常時表示をやめる。
