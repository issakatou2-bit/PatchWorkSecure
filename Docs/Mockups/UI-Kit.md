# UIキット — 全画面で共通の部品（2026-09-28）

見本は`ui-kit.html`（ブラウザで開く）。目的は、旧デザインのウィンドウや画面遷移をなくし、細部の安っぽさを直して、大手ゲームのような仕上がりにそろえること。
**現在の作業（事件画面・季節演出）が終わってから着手する。** 見た目はモックを正とする。

## 1. 最初にやること：標準ウィンドウの作り直し

ウィンドウ48か所は、すべて`OpsGame.UI.cs`の`Dialog()`から作られている。**この1か所を`ui-kit.html`の「標準ウィンドウ」に作り直せば、ほぼ全部が一度にそろう。**
その後、`Dialog()`を通さずに独自に組んでいる窓と、画面の切り替えを探し、同じ部品に置き換える。旧デザインの色（チャコール地の窓など）が残っている箇所を一覧にしてから直すこと。

標準ウィンドウの仕様：
- 見出しは色帯（ピンクのグラデーション＋右端に斜めの縞）。上に英字の小見出し（KNOWLEDGEなど、字間を広く）、下に日本語の題名。
- 縁は白とピンクの二重。右上に白い丸の閉じるボタン。
- 背景は暗くしてぼかす。0.45秒で、少し行き過ぎて戻る動きで出る。消えるときは0.2秒。
- 下にボタン：左に「閉じる」（白）、右に主な操作（ピンク、幅2倍）。

## 2. 部品の標準

| 部品 | 仕様 |
|---|---|
| ボタン | 上が明るいグラデーション、上端に白い光の線、下に濃い段差（6px）。押すと4px沈み、0.96倍→1.02倍→1倍で戻る。種類は4つ：ピンク＝主な操作、金＝特別な操作（導入など）、白＝通常、紺＝進行（月を進める）。押せないものは灰色 |
| パネル | 白い縁3px＋細い灰の線＋ふんわりした影の三層。地の色は真っ白ではなく、上から下へごく薄い灰 |
| 見出しの帯 | 斜めに切った色帯。パネルの左上に置く |
| ランク文字 | 色のグラデーション、白い縁、下側の内側の影、文字にも影 |
| 札 | 角の丸い小さな札。色は意味で固定（攻撃の種類＝ピンク、報酬＝水色、未確認＝黄、新しい＝紺地に黄） |
| 大きい数字 | 文字にグラデーション。増えた値は0.6秒で数え上げ、止まる瞬間に1.1倍 |
| ゲージ | 上側に光の線を入れる |

## 3. このゲームだけの模様：ツギハギ

題名の「PatchWork」から、**縫い目の点線**と**少し傾いた当て布の形**を共通の模様にする。判子（達成など）、バッジ（Lv・NEW）、パネルの内側の縁に使う。
他作品の見た目をまねるだけでなく、このゲームの顔になる要素として扱う。

## 4. 動きの決まりごと

- 出る：0.35〜0.45秒、少し行き過ぎて戻る。子の部品は0.04秒ずつずらして順に出す。
- 消える：0.2秒（出るより速く）。
- 画面遷移：ピンクの斜めの帯が0.3秒で横切る（`Next-Screens.md`の表と同じ）。
- **何も動かずに、急に出たり消えたりする部品を作らない。**
- 動きを減らす設定では、位置と拡大縮小の動きを止め、透明度の変化だけにする。

## 5. 仕上げの確認

- 全画面のスクリーンショットを撮り、旧デザインが残っていないかを一覧で確認する。
- ボタン・パネル・ウィンドウの縁と影が、画面ごとに違っていないかを確認する。
- 文字の大きさの段階をそろえる（見出し・本文・補助の3段階程度）。
