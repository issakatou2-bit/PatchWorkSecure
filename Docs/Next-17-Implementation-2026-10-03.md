# Next-17 ゲームパッド操作

## ① 通常画面

- Input System の `Gamepad` を使い、南ボタン＝決定、東＝戻る、Start＝設定、十字キー/左スティック＝近い選択肢へ移動。Xbox/PS/Steam Deckで同じ配置。実機確認は未実施。
- 既存の `OpsButtonFeedback` / `OpsCardLift` / `OpsPlanningHover` の選択表示を再利用。新しい絵・UI部品を追加しない。設定のスライダーは左右で5%ずつ変更、一覧は選択先までスクロール。
- 開いている窓だけを選択対象にし、月報は次の月、計画は調べるを初期選択。ガイド中は案内先と説明を飛ばす操作を選べる。
- 日記帳の既読ページはLB/RBで前後へ。通常の月報からの日記では未読の未来ページに進まない。
- 既定UIアクションを実行時コピーし、ゲームパッドの決定/移動が二重に入らないようにする。元のアセット・シーン・マウス操作は変更せず、破棄時に元へ戻す。既定の全デバイスSubmitをキーボードEnterに限定。
- 関係分：Next17Menus 1/1、既存Next15Displayの設定保存 1/1。両解像度の撮影と既存ホバー/モックとの比較を `Artifacts/Next17/` に保存。
