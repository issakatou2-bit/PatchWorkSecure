# Next-23 — 待ちと飛ばし方の統一

## 実装

`OpsPresentationTiming`へ見せる時間の既存値と速さの倍率を集約し、`OpsPresentationWait`で経過・初回・終端・スキップを扱う。初回は入力を演出だけで消費して最後へ飛ばさず、同じ種類の再訪ではクリック・決定・ゲームパッド南ボタンで終端へ進む。速い設定は同じ時計を2倍で進める。初回判定は従来の月替わり・年間評価と同じく、起動中の画面側の記録であり、新しい保存キーは追加しない。

対象は共通入場／退場、タイトルのロゴ、月替わり・事件入口、事件の発動／針／余韻、月報の数え上げ、年間評価、因子、日記の開き／書き込み／シール、年度の開幕、B〜Gの終了待ち／数え上げ／判子、ひなたの入場／ポーズ交換、成長ゲージ／粒／ランク、社員の移動、予算コイン、導入完了札／部屋の膨らみ、事件の部屋ズームと支出ゲージの残像。時間と曲線の標準値・最終配置は維持する。複数の待ちが重なる場合も一度の入力で終端を要求し、その入力を次画面の操作へ渡さない。設定窓が開いている間は窓の待ちだけを操作する。

飛ばす時は声を止め、ミニゲームの結果画面で後から格言音声を開始しない。字幕・最終の数字・判子は残す。破棄／非表示の画面の待ちは終了扱いにし、別画面に残って操作を塞がない。作られたフレームの時間（作られる前の読み込みを含む）は加算せず、ポーズ交換が上書きされたら前の待ちを終了する。

遊びの最中の入力は演出スキップに使わない。成功の表示やひなたの反応も次の判断を塞がない。制限時間、採点、出現間隔、復旧の進行、ヒットストップ、遊び中のメール入退場・依頼入場は既存の時計のまま。常時の呼吸・瞬き・口パク、音声自体の速度・BGM／SEの音の長さも変更しない。旧版は今回の待ち時計を使わず、回帰確認だけ。
