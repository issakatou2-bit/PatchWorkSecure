# オフィス中心のゲーム体験への改修 — 2026-09-13

## 方針

作り直し先は既存Unityプロジェクト。情シスとして「人を支えながら、平穏なオフィスを一年守る」芯、攻撃10種・対策8種、防御率計算、教育記録は維持する。
新しい別ゲームや別エンジンへの移植は行わない。

参考画像 `preview.webp` に合わせた素材の出自: [素材記録](Reference-Asset-Provenance.md)。背景と暫定ひなたの原画には画像生成を使用。ひなたは依頼に合わせて背景を透過し、制服から仕事着へ編集した。人間が描いた完成イラストとは扱わない。操作UI・文字・対策アイコンはUnityで描画する。

## ソースに実装したもの

- 見下ろしドット絵オフィス、濃紺の枠、クリーム色の吹き出し。左に対策8種、右に判断、右下にひなた1人。タイトルは専用レイアウト。
- 対策8種をコンパクトに一覧表示し、種類ごとの図形アイコンを追加。カーソル・選択時に役割、次の強化のストレス変動・予測被害軽減を表示。
- ゲージに項目名と数値を維持。塗りつぶし用スプライト未指定で満タンに見える問題を修正。
- ひなたの通常立ち絵を本物の透過PNGとして投入。未投入の表情は通常絵へフォールバック。カーディガン・パンツ・社員証の仕事着とし、手描き完成素材への差し替え仕様を [制作仕様](Hinata-Art-Brief.md) に記録。
- 通常プレイはクイズなしで出勤。教育用の事前・事後クイズは別の開始ボタンから維持。
- 相談対応は人望増＋ストレス3、休息は人望-2＋ストレス-6。両方に同額の売上が入ることを明示。
- 対応選択前に防御率、費用、ストレスを提示。結果に設備・対応・タイミング・人望・疲労の内訳を表示。
- 相談解決、防御成功、防いだ想定損失、復旧による損失軽減を記録・表示。
- 13種類の短い電子音を音源未設定時だけ生成。BGMはまだ未設定。
- 設定中はゲームを停止。タイトルに戻る際は古い遷移処理を終了。主要操作の連打による二重処理を抑止。
- フォントは既存アトラスの `m_IsReadable: 0` を `1` に修正。再構築時にも読み書き状態と文字追加を検査する。
- 未完成のアリア・クロエは選択肢から外し、アセット自体は保持。

- Unity PlayModeテストは9件実行・9件成功・失敗0件。タイトル、学習クイズ、相談、攻撃、対応、結果、中断復帰、ゲージ、立ち絵透過、対策の説明を確認。
- 1600×900と1280×720の実描画を確認。以前の4件しか見えない対策一覧、満タン固定に見えるゲージ、図形の代役キャラは解消。テスト中の文字欠け警告は0件。

- 実物のGameStateに対する相談・上限・終了後変更防止・結果内訳・プレビュー非破壊の検証成功。
