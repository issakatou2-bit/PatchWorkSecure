# 承認モックの計画画面への移行

基準は `Docs/Mockups/planning-screen.html` と同README。独自の再デザインではなく、1600×900の位置・大きさ・色・形・動きをUnityのuGUIへ移す。対象はCompanyYearの計画画面のみ。事件・月報・年間評価・旧版SampleSceneのデザインは維持する。

## 対応とデータ

- ステージ352,108／900×792、会社の力24,108／312×612、相談1268,108／308×237.2、ひなた230,450／470×470、会話600,540／420×129.2、行動660,740／916×144。上部と今年の目標もHTMLの寸法を反映。
- 新しい `OpsGame.Planning.cs` が計画画面だけを描画。既存の導入比較・運用ノートは重ねる詳細画面として再利用する。ルール・抽選・予算・工数・セーブは変更しない。
- 会社の6能力・平均ランク・余力はREADMEの式に従う。ランクは境界値16ケースで確認する。余力は表示だけ100−疲労、休息のルールは従来通り。
- 相談者の丸には実際の役職、詳細には氏名・相談・ニュース・社内依頼の条件。見本の「信頼+5」は実際の報酬「+3」へ置き換える。
- 見本の「おすすめ2件」を捏造せず、実際に導入条件を満たす件数を「導入できるN件」として表示する。
- サーバーランプと設備印は未整備を灰色、導入済みを緑。!は相談、?は未対応の日常チケット。常設の文字ラベルは消し、ポインター・キーボード選択時だけ説明を出す。
- 日常チケット、運用チーム、運用ノート、3番目の成長目標、社内事情、遊び方はメニューから開ける。削除はしていない。
- 社員の事件対応への加算・日常チケット委任はそのまま有効。現在の4つの計画行動には社員による追加効果の判定がなく、関わった社員が経験値を得る仕組みだけがある。そのため経験獲得を支援と見せかけた顔マークは付けていない。`OpsGame.Team`の表示と`OpsState.Growth`の実ルールを照合した。新たな計画行動の支援ルールは今回追加しない。

## 表現

ぼかし背景・斜めグラデーション・上だけ丸いステージ・9-sliceの丸パネル・柔らかい影・斜めの帯・SVGと同じ形の図形アイコンをコードで制作。`Tools/Generate-PlanningUI.py`、来歴は `Docs/Reference-Asset-Provenance.md`。

ひなたの上下10px/3.2秒、印の跳ね8px/1.6秒、ボタンの光2.8秒、相談の輪1.8秒、導入済みランプ1.1秒。4月だけ桜6枚、8月は日差し、12月は雪6枚。ReducedMotionで移動・回転・拡縮を止める。光と季節粒子は低減時に非表示、意味のある設備印・相談印は残す。

操作ボタンは下6pxの影、押すと同じ距離だけ沈む。フォントは現行のM PLUS Rounded 1c／Zen Kaku Gothic New。衣装案Aは未承認なので既存の暫定ひなたを使う。

## 比較・検証

専用テストは部品の実座標、実数値、メニューの全導線、3解像度、季節、動き低減、文字欠け、クリック遮蔽を確認する。既存の画面操作テストも、常設をやめた情報を実際のメニュー／相談ボタンから辿るよう更新する。検証用に見えない旧ボタンを残してはいない。

比較画像は `Artifacts/planning-comparison.png`（左：承認モック、右：Unity）。IABの保存画像の描画縮尺0.8を正規化して同じ1600×900で比較。相談内容・報酬・導入件数・社員支援の有無は実データを正とするため、モックの固定値とは区別する。

### 完了時の確認

- PlayMode全件：82/82成功、失敗・スキップ0（345.35秒）。最終結果は`Artifacts/planning-playmode-final.json`。新試作73件＋旧版9件。日本語グリフ欠け・ゲーム例外なし。
- UIからの仮想操作：ゲーマー・初学者・FE取得者役で各5年度、合計15年度を完走。人間による楽しさの評価ではない。
- Verify-Core、Verify-CompanyOps、Verify-CompanyOps-Personas成功。Compile-Officeの本体・Editor・Testsも成功。ルールのファイルは今回変更していない。
- 1280×720・1600×900・1920×1080を撮影。モックと並べ、相談印の欠け・工数の形・星の色・押下の沈み込みを修正した。画像は`Artifacts/CompanyOps/46-approved-planning.png`～`48-approved-planning-1080.png`。
- Windows版を更新。実行版でもBGM2曲の切替と年間12か月がPASSED（`Artifacts/company-player-planning-20260928.log`）。素材・制作記録も同梱。Unity由来の通信接続エラーと終了時ComputeBuffer解放警告は残るが、ゲームの検証は成功。
- ビルドによる一時設定を戻し、EditorのCompanyYearを開き直した。ユーザーのセーブ・音量設定はテストで変更していない。
