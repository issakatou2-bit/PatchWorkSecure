# 10大脅威の調べ（キャラ付けの材料）（Claude、2026-10-03、第2版）

加藤さんの指示（10/3）：10大脅威それぞれの重要な単語・概念・関連する要素・社会からの印象を調べ、キャラ付けに生かす。名前は手口の言葉にちなむ（「クリプタ」→「クリプト＝暗号」と覚えられるように）。

## 00. 第2版で足したこと（IPAの解説書で確かめた用語）

出典：IPA「情報セキュリティ10大脅威 2026 解説書［組織編］」（2026年3月、64ページ。`https://www.ipa.go.jp/security/10threats/omgdg50000008fi8-att/kaisetsu_2026_soshiki.pdf`、10/3に読んだ。文字にしたものは`Artifacts/Research/`、gitでは追跡しない）。下の用語は解説書に出てくることを確かめた（◆の見出しと本文）。キャラの技・図鑑の文に使ってよい。文に使うときは、意味を解説書と照らし合わせる。

| 順位 | 解説書の手口（◆の見出し）と用語 |
|---|---|
| 1 ランサム | 機器の脆弱性を悪用してネットワークから感染／不正アクセス（窃取した認証情報）／Webサイトやメールから感染／ダークウェブ／グループ会社を経由。用語：ランサムウェア、**ノーウェアランサム**（暗号化せずに脅す）、**二重脅迫**、三重・四重脅迫、**RaaS**（Ransomware as a Service：攻撃の代行・売買） |
| 2 サプライチェーン | 関連会社・業務委託先を攻撃／ソフトウェア開発元のソフトウェアにマルウェアを仕込む／**MSP**（管理を請け負う事業者）の資産管理ソフトを悪用／委託先へのランサム攻撃／正規のWebサイトを足掛かりに。用語：サプライチェーン（ビジネス上の繋がり）、**ソフトウェアサプライチェーン**（ソフトウェアの繋がり）、**SBOM**（ソフトウェア部品構成表）、委託先の監査、外部認証（ISMS・Pマーク・SOC2） |
| 3 AI | 許可なくAIを業務利用（**シャドーAI**）／実在しない情報の生成（**ハルシネーション**）／AIを助力にした脅威の増長／AIの脆弱性。用語：**プロンプトインジェクション**、**間接プロンプトインジェクション**（AIが読んだ文書に仕込まれた指示）、**ジェイルブレイク**（保護を外す）、AIが提案した存在しない部品名を悪用したサプライチェーン攻撃 |
| 4 脆弱性 | 公表される前の脆弱性を悪用（**ゼロデイ攻撃**）／対策する前の脆弱性を悪用（**Nデイ攻撃**、Nデイ脆弱性）／攻撃ツール・攻撃サービス。用語：**PoC**（概念実証）、パッチ、回避策、SBOM |
| 5 標的型 | 不正アクセス／メールを用いた攻撃／Webサイトの改ざん（**水飲み場型攻撃**）／**ネットワーク貫通型攻撃**（境界のVPN機器などを踏み台に） |
| 6 地政学 | DDoS攻撃／ランサム攻撃を偽装したサイバー攻撃／ネットワーク貫通型攻撃／スピアフィッシングによる情報窃取／**偽情報の流布**。用語：**影響工作**、情報戦・**認知戦**、ディープフェイク |
| 7 内部不正 | **アクセス権限の悪用**／在職中に割り当てられたアカウントの悪用（退職後も使えると危ない）／内部情報の不正な持ち出し。用語：**不正のトライアングル**（動機・機会・正当化） |
| 8 リモートワーク | リモートワーク用製品の脆弱性等の悪用／アカウント情報の不正利用／リモートワーク用端末への攻撃 |
| 9 DDoS | **ボットネット**（IoT機器などの乗っ取られた機器の群れ）／**フラッド攻撃**（SYNフラッド・ACKフラッド・FINフラッド）／**リフレクション攻撃**（DNS・NTPのサーバーを反射に使う）／**ランダムサブドメイン攻撃（DNS水責め攻撃）**／DDoS代行サービス |
| 10 BEC | BECの準備としての情報窃取／取引先へのなりすまし／経営者等へのなりすまし（**CEO詐欺**）／社外の権威ある第三者へのなりすまし。用語：ディープフェイク、「緊急」「他の従業員には秘密」と急がせる |

**全部の脅威に共通する「攻撃の糸口」6つと「情報セキュリティ対策の基本」**（解説書の表1.2）：ソフトウェアの脆弱性→ソフトウェアの更新／マルウェアの利用→セキュリティソフトの利用／パスワード窃取→パスワードの管理・認証の強化／設定不備→設定の見直し／データの暗号化→バックアップの取得／ソーシャルエンジニアリング（罠にはめる）→脅威・手口を知る。
→ **対戦のミニゲームの「属性」にできる**：技ごとに糸口（6種）があり、手札の備えがどの糸口に効くかで受ける。解説書の考え方そのものなので、教育として正確。

## 1. 10人の材料

各脅威：重要な言葉（覚えてほしい用語）／技にできる手口／効く備え（ゲームの設備・行動）／社会の印象／名前の案（由来）／性格の手がかり。

### 1位 ランサム攻撃による被害 — クリプタ（決定）
- 言葉：ランサムウェア、暗号化、身代金（ランサム）、二重脅迫（暗号化＋持ち出したデータの公開をちらつかせる）、ノーウェアランサム（暗号化せず盗んで脅す）、侵入口（VPN機器・リモートデスクトップ）、バックアップの破壊。
- 技：「VPNのすき間から入る」「ぜーんぶ暗号化」「持ち出して二重に脅す」「バックアップも狙う」。
- 備え：修正の適用、多要素認証、EDR、ネットワークの区切り、**戻せるバックアップ（別の場所・書き換えられない形）**、復旧の手順と訓練。身代金を払っても戻る保証は無い。
- 印象：11年連続1位の「横綱」。業務・出荷・病院の診療が止まるニュースで知られる。
- 名前：クリプタ（crypt-＝隠す。暗号＝cryptography と同じ根っこ）。性格：女王、やかましく生意気（決定）。

### 2位 サプライチェーンや委託先を狙った攻撃
- 言葉：サプライチェーン（取引の鎖）、委託先・取引先、保守用の接続（リモート保守）、ソフトウェアの更新に紛れ込ませる、「一番弱い輪から入る」。
- 技：「委託先の保守IDで入る」「更新ファイルに紛れ込む」「取引先を踏み台にする」。
- 備え：委託先の管理（契約・点検）、保守の接続を必要な時だけ開ける、最小権限、ゼロトラスト、台帳（何がどこにつながっているか）。
- 印象：「自分の会社は守っていても、取引先から入られる」。8年連続。
- 名前の案：**リンカ**（link＝鎖の輪。「鎖の一番弱い輪」を狙う）、ヴェンダ（vendor＝委託先）。性格：眠たげでずる賢い、ちゃっかり者。
- 絵の要素：つながった配達の箱の鎖（工場→彼女→会社）、借り物の作業帽、顔写真の無い身分証、合鍵の束。

### 3位 AIの利用をめぐるサイバーリスク（初選出）
- 言葉：生成AI、ディープフェイク（声・映像のなりすまし）、ハルシネーション（もっともらしい誤り）、プロンプトインジェクション（文書に仕込んだ指示でAIを操る）、シャドーAI（許可されていないAIの利用）、入力した情報の漏えい、権利侵害、生成結果の確認不足。
- 技：「声と映像でなりすます」「AIに秘密を打ち込ませる」「もっともらしい嘘を混ぜる」「指示を仕込んで操る」。
- 備え：AIの使い方の決まり（入れてよい情報）、生成結果を人が確かめる、既知の連絡経路での本人確認、教育。**AIそのものを悪者にしない**（使い方の危うさと悪用が脅威）。
- 印象：便利さとの裏表。新しい脅威として注目。
- 名前の案：**ミミカ**（mimic＝まねる。声も顔も文もまねる）、フェイカ（fake）。性格：芝居がかって気取る、すぐ別人になりきる。
- 絵の要素：笑顔の仮面と別の表情の仮面、画素と吹き出しにほどける裾、声の波。

### 4位 システムの脆弱性を悪用した攻撃
- 言葉：脆弱性（ぜいじゃくせい）、修正プログラム（パッチ）、ゼロデイ（修正が出る前の攻撃）、公開から悪用までの短さ、古い機器・サポート切れ、インターネットに出ている機器。
- 技：「ひびから入る」「修正が出る前に突く」「サポート切れを狙う」。
- 備え：修正の適用（早く）、機器の台帳、サポート切れの入れ替え、外から見える機器を減らす、監視。
- 印象：「アップデートして」と言われる理由。6年連続。
- 名前の案（10/3、加藤さんの案）：**ヴァルネラ**（vulnerability＝脆弱性。仲間うちの呼び名は「ネラ」または「ルネ」）。ひなたたちは「脆弱性（ヴァルネラビリティ）」と呼び、敵どうしは略して呼ぶ。ほかの案：クラッカ（crack＝ひび）、ゼロディ（zero-day）。性格：すばしこく、いたずら好き、修正（ばんそうこう）が大の苦手。
- 絵の要素：体や服のひび、小さな虫（バグ）の手下、ばんそうこう。

### 5位 機密情報を狙った標的型攻撃
- 言葉：標的型攻撃メール、スピアフィッシング（狙いを定めたフィッシング）、APT（長く潜む攻撃）、水飲み場型、潜伏、横への移動（ラテラルムーブメント）、持ち出し。
- 技：「あなただけへのメール」「何か月も潜む」「拠点から拠点へ渡る」。
- 備え：教育（怪しいメールの報告）、EDR、ログの監視、ネットワークの区切り、脅威情報の共有。
- 印象：国家の関与や産業スパイの話題。11年連続。
- 名前の案：**スピア**（spear＝もり。スピアフィッシング）、アプティ（APT）。性格：冷静で執念深い、獲物を決めたら離さない。
- 絵の要素：封筒を餌にした釣り竿（もり）、照準の瞳、LANケーブルのしっぽ。

### 6位 地政学的リスクに起因するサイバー攻撃（情報戦を含む）
- 言葉：地政学的リスク、国際情勢、情報戦、偽情報（ディスインフォメーション）、世論操作、ハクティビスト、重要インフラ。
- 技：「うわさを広げる」「本物そっくりの偽ニュース」「騒ぎに乗じて攻める」。
- 備え：情報の出どころを確かめる、公式の発表で確認、重要なシステムの備え（他の脅威と同じ基本）。
- 印象：ニュースの国際情勢と結びつく。2年連続、7位→6位。
- **注意：特定の国・民族・旗・軍服・言語を連想させない。**「国」ではなく「うわさ・偽情報」を形にする。
- 名前の案：**ルモア**（rumor＝うわさ）、プロパ（propaganda）。性格：口がうまく騒がしい、すぐ話を盛る。
- 絵の要素：新聞と吹き出しの服、ちらしの翼、拡声器。

### 7位 内部不正による情報漏えい等
- 言葉：内部不正、権限、持ち出し、退職者・異動者、記録（ログ）、最小権限、「不正のトライアングル（動機・機会・正当化）」。
- 技：「残った権限で開ける」「こっそり持ち出す」「『みんなやってる』とささやく」。
- 備え：権限の見直し（異動・退職のとき）、記録と監査、持ち出しの決まり、相談しやすい職場（動機を減らす）。
- 印象：退職者による顧客情報の持ち出しのニュース。11年連続。
- **注意：社員を悪者にしない（性弱説）。** 人ではなく「機会（権限のすき間）と誘惑」の化身にする。倒し方は仕組み（権限の見直しと記録）。
- 名前の案：**スキマ**（隙間＝機会）、インサ（insider）。性格：気まぐれな猫、すき間を見つけると入りたくなる。
- 絵の要素：猫耳の精、合鍵とUSBメモリ、すき間から顔を出す。

### 8位 リモートワーク等の環境や仕組みを狙った攻撃
- 言葉：VPN、リモートデスクトップ、家庭のネットワーク（ルーター）、私物の端末、クラウドの設定、在宅勤務。
- 技：「VPN機器の古いすき間」「家のルーターから」「公衆Wi-Fiで盗み見る」。
- 備え：VPN機器の修正、多要素認証、端末の管理、ゼロトラスト。
- 印象：コロナ禍以降の在宅勤務で広まった。6年連続。
- 名前の案：**リモ**（remote）、トンネ（VPNのトンネル）。性格：のんびり甘え上手、家に上がり込む。
- 絵の要素：家の形のフード、電波のアホ毛、細いトンネルのマフラー。

### 9位 DDoS攻撃（分散型サービス妨害攻撃）
- 言葉：DDoS、分散（たくさんの所から）、ボットネット（乗っ取られた機器の群れ）、大量の通信、つながらない、サービス停止。
- 技：「みんなで押し寄せる」「乗っ取った機器を操る」「つながらなくする」。
- 備え：通信の量を見張る、回線・クラウドの防御サービス、止まったときの案内（業務の続け方）。
- 印象：サイトやアプリに「つながらない」で気づく。2年連続。
- 名前の案：**フラディ**（flood＝洪水。フラッド攻撃。加藤さん「フラッドいい」）、ボッタ（bot＝乗っ取られた機器）。性格：にぎやか、数で押す。
- 絵の要素：そっくりな小さな分身がたくさん、渋滞の矢印、応援団の拡声器。

### 10位 ビジネスメール詐欺
- 言葉：ビジネスメール詐欺（BEC）、なりすまし、振込先の変更、偽の請求書、経営者のふり、急がせる・内密に。
- 技：「振込先が変わりました」「社長です、急ぎで」「本物そっくりのやりとりに割り込む」。
- 備え：既知の連絡先で確かめる（電話など別の経路）、振込の承認の決まり（二人で確認）、教育。
- 印象：海外送金の詐欺被害。9年連続。
- 名前の案：**ミラ**（mirror＝鏡。本物と偽物が並ぶ）、レタ（letter）。性格：上品で得意げ、口調は丁寧。
- 絵の要素：封蝋の髪飾り、手に持った封筒と矢印の請求書、鏡写しの偽物。

## 2. 名前の決まり

- **呼び分け**（10/3、加藤さんの案）：ひなたたち（守る側）は、脅威を正式な言葉で呼ぶ（「ランサムウェア」「脆弱性（ヴァルネラビリティ）」）。敵どうしは名前の略で呼び合う（「ネラ」「クリプ」）。用語と名前の両方が自然に耳に残る。

- カタカナ2〜4文字、手口の言葉にちなむ（覚えると用語につながる）。
- 実在の人・有名な作品のキャラ・会社名・国名と重ならないか、決める前に調べる（クリプター＝FGOのように）。国名に聞こえる名前（例：「チェーン」→「チェイナ」）は使わない。
- 名乗りの型：「あたしは○○。△△の○○！」（△△＝手口の言葉）。

## 4. 応用情報・支援士の言葉をゲーム全体に（10/3、加藤さん「APやSCにちなんだ単語を、名前・手法・概念・ゲーム全体に」）

試験（応用情報技術者AP・情報処理安全確保支援士SC）で問われる言葉を、技の名前・備えの名前・図鑑の説明・ひなたの日記の勉強の話に使う。ひなたが2年目に応用情報、3年目に支援士に合格する連載とつながる。

| 使う所 | 言葉の例（解説書・試験でよく出るもの） |
|---|---|
| 技（攻撃手法） | 二重脅迫、ノーウェアランサム、RaaS、ゼロデイ攻撃、Nデイ攻撃、水飲み場型攻撃、スピアフィッシング、ネットワーク貫通型攻撃、ラテラルムーブメント、SYNフラッド、リフレクション攻撃、DNS水責め攻撃、プロンプトインジェクション、CEO詐欺、権限昇格、パスワードリスト攻撃、ブルートフォース攻撃、SQLインジェクション、クロスサイトスクリプティング |
| 備え（対策） | 多層防御、最小権限、職務分掌、ゼロトラスト、多要素認証、EDR、WAF、IDS/IPS、DMZ、SIEM、CSIRT、BCP、RTO/RPO、3-2-1バックアップ、SBOM、脆弱性診断、ペネトレーションテスト、ログの監視 |
| 概念（図鑑・格言・日記） | 機密性・完全性・可用性（CIA）、リスクアセスメント、不正のトライアングル、サプライチェーン、ソーシャルエンジニアリング、インシデントレスポンス、フォレンジック |

- 技・備えの説明は点検の決まりに従い、意味を解説書・IPAの資料・試験のシラバスで確かめてから書く（言葉だけを借りて意味を変えない）。
- ハッシュ・ソルト・ペッパー（パスワードの保存）は暗号化とは別物。使うなら「パスワードリスト攻撃」に対する備えの側で、正しい意味で出す。
