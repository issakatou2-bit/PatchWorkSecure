# ストアページと宣伝の計画（Claude、2026-10-02）

加藤さんの質問「ストアページや動画で、宣伝を始めたほうがいい？」への案。**SNSの短い動画は今から、Steamのストアページは12月〜1月**。目標は2027年6月のSteam Next Fest（登録の締め切りは4月25日の見込み。体験版とストアページが要る）。

## 1. 宣伝に使ってよい素材・だめな素材

| 素材 | 宣伝に使えるか | 根拠・注意 |
|---|---|---|
| ひなたの声（ElevenLabs無料プラン） | **使えない** | 無料プランの音声は商用利用不可。私的試遊だけ。字幕で見せる |
| かのん・りりぃの声（Irodori-TTS） | 使える | 条件は`Docs/Reference-Asset-Provenance.md`（v4.1-SmallはMIT、v4-Largeの量子化版はGemmaの利用条件）。AIの声であることを明記 |
| キャラ絵・二人絵・強敵の影絵（ChatGPT） | 使える | Steamでは「AIで作った内容」の申告が要る。ほかの作品に似せた絵は使わない |
| BGM（Gemini/Lyria） | **要確認** | 公開・収益化での利用条件を確かめてから。確認前は無音か効果音だけで作る |
| 効果音・フォント | 出典どおり | `Docs/Reference-Asset-Provenance.md`の条件に従う（フォントはOFLなど） |

## 2. 最初の宣伝動画（30秒、縦にも横にも切り出せる構図）

音：かのん・りりぃの声と効果音だけ。ひなたは字幕で話す。BGMは確認が済むまで入れない。

| 秒 | 画面 | 文字・声 |
|---|---|---|
| 0〜3 | 平穏なオフィス。ひなたが手を振る | 字幕「なにごともない、いつもの平穏。」 |
| 3〜7 | 計画画面。カードを選んで判子 | 字幕「情シスの仕事は、守る順番を選ぶこと」 |
| 7〜11 | 警告。画面が揺れ、事件の札 | 字幕「でも、事件はいつも急に来る」 |
| 11〜17 | ミニゲーム（封じ込め・メール判定・ログ）を2秒ずつ | 効果音。成功の判子 |
| 17〜21 | 強敵の影絵が3体並ぶ | りりぃ「正体、分かった。……思ったより、地味な手口。」 |
| 21〜25 | 3人の二人絵を順に | かのん「数字はわたしが作るわ。あなたたちは、守ることに集中して。」 |
| 25〜30 | タイトルとロゴ、「ウィッシュリストに登録」 | 字幕「PatchWorkSecure」 |

- そのほかの短い動画の題材（15秒）：「怪しいメールを見抜けるか」「ランサムウェアからの復旧」「ひなたの日記」「3年目の総決算」。
- 実在の会社・製品の名前、実在のIPアドレス・ドメインを出さない（`Docs/Fact-Check-2026-10-02.md`の決まり）。

## 3. Steamのストアページに要るもの

申請・登録（加藤さん本人が行う）：Steamworksの登録料（1作品100ドル）、本人確認・税の情報・振込先の登録。登録料を払ってから発売まで30日以上、「近日登場」のページは発売の2週間以上前に公開しておく必要がある。

| 素材 | 大きさ（px） | 中身の案 |
|---|---|---|
| ヘッダー | 920×430 | 3人の集合絵＋ロゴ |
| 小さいカプセル | 462×174 | ロゴを大きく、ひなたの顔 |
| メインカプセル | 1232×706 | 集合絵＋ロゴ（ストアの目立つ場所に出る） |
| 縦長カプセル | 748×896 | ひなたの全身＋ロゴ |
| ページの背景 | 1438×810 | オフィスの背景をぼかしたもの |
| ライブラリのカプセル | 600×900 | 縦長カプセルと同じ構図 |
| ライブラリのヘッダー | 920×430 | ヘッダーと同じ |
| ライブラリの大きな絵 | 3840×1240 | 文字なしの横長の集合絵 |
| ライブラリのロゴ | 1280×720（透明） | ロゴだけ |
| 画面写真 | 1920×1080、5枚以上 | 下の一覧（Next-14③で撮る） |
| トレーラー | 1〜2分 | 2章の30秒版をもとに伸ばす |

大きさはSteamworksの最新の案内で最後に確かめる（時々変わる）。

- 画面写真の一覧：タイトル、計画、事件の判断、ミニゲームB〜G、月報、年間評価、日記帳、2年目の開幕演出、強敵の札、終わりなき年度。
- 文章：短い説明（ストアの上に出る数行）、長い説明、タグ（シミュレーション、教育、カジュアル、かわいい、など）、AIで作った内容の申告（絵・声・音楽のどこに使ったか）、年齢区分の質問票。
- 言語：最初は日本語。英語の字幕があると、見てもらえる人がかなり増える（翻訳は後で検討）。
