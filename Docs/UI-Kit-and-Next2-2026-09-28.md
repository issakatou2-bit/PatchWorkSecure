# 共通UIと次画面2の移行

## 作業前の旧デザイン一覧

- `OpsGame.UI.Dialog`：白い本文だが無地の見出し、紺の閉じるボタン、即時表示。詳細・知識・育成などが共通で使用。
- `PlanningOverlay`：導入一覧だけ独自のチャコール窓。
- `Box`／`Button`：タイトル、履歴、育成、内訳の濃色パネルと単色ボタン。
- `Review`／`Ending`：旧ダッシュボードの右パネル／横長評価。今回の月報・年間評価モックへ移す。
- `Menu`：設定がクリックで循環するボタン。モックのスライダー・切替へ移す。
- 事件／計画：承認モックへ移行済み。配置を保ち、共通の縁・グラデーション・押下反応へ揃える。

## 方針

UI／uGUIスキルを使用。`UI-Kit.md`と4枚のHTMLを正とし、共通部品を先に変更した後、①チュートリアル→②月報→③年間評価→④設定の順に実装する。絵の無いまばたき・口パクは1枚絵へフォールバックし、顔は描き直さない。効果音候補は承認前にゲームへ登録しない。

## 実装した範囲（2026-09-29）

1. 共通キット：ピンクの帯、斜線、英語分類、白い丸の閉じるボタン、白／ピンクの二重縁、4種類のグラデーションボタン、6pxの段差と4pxの押下。詳細窓と導入一覧も共通化。開くときは0.45秒の弾み、閉じるときは0.2秒のフェード。背景は現在表示中のUIを低解像度で撮影し、ぼかして暗くする。独自シェーダーは使用していない。
2. チュートリアル：新しい一年の初回4月だけ、6段階を実際の操作で進める。対象以外の操作を遮り、黄色い枠と指を表示。「次へ」は置かず、詳細を閉じる・調査・実際の導入・月を進める・対応で進む。飛ばしても数値や抽選結果は変わらない。設定から再表示できる。
3. 月報：被害・業務停止・対応費の3枚、成長、依頼、社員支援、ひなた、下端2ボタンをモックの座標・寸法で配置。実際の見積もりと月初／月末の指標を新規記録へ保存。旧記録の未保存値は「未記録」と表示する。支援が無い月は「今月は支援なし」。長い学習情報は「記録を見る」から開く。
4. 年間評価：大きなランク判子と得点の数え上げ、12か月の段階表示、設備MVP・社員支援回数・遭遇数・成長目標を配置。途中終了では紙吹雪やクリア扱いを出さない。設備の個別比較は連携が重なるため、各設備の合計を会社全体の軽減額と偽らない。
5. 設定：3本の実スライダー、文字サイズ3段階、字幕、省演出、2回目以降の割込短縮。変更は即時反映・保存。記録削除は確認必須で、この試作の進行ファイルだけを退避してから削除扱いにする。旧版と音量・表示設定は維持。「記録・試聴」から従来の履歴・試聴・ナビ選択にアクセスできる。
6. ひなた：`NavigatorPersona.AnimationFrames`で表情ごとの半目・閉じ目・開口・中間口を設定する仕組み。まばたき3〜5秒／合計0.15秒、文字送り中の口パク0.08〜0.12秒、声を登録した場合は音量に連動。ゲームの抽選乱数を消費しない。現時点では差分もゲーム内ボイスも無いため、元の1枚絵を変えず表示する。
7. 効果音：11場面×2セットをWAV化し、試聴用の連続再生も作成。加藤さんがプロシージャル生成の候補制作を承認。**試聴・採用の承認前なのでゲーム未投入**。`Docs/Sfx-Candidates-2026-09-29.md`。

## 数値・未実装を区別する

- 報酬と難易度の計算は変更していない。社内依頼の報酬は現行ルールの信頼+3・年間+45点。未実装の予算+5は表示しない。
- ランクアップに伴う新しい閾値ボーナスは未実装。成長欄には現在実際に効く継続的な恩恵だけを記載する。
- 図鑑はこの年度の遭遇IDの集計と表示枠まで。別年度をまたぐ図鑑・一覧画面は未実装。年度履歴に遭遇IDを保存する。
- 顔の差分素材は未投入。まばたき・口パクの見た目が完成したとは扱わない。
- `Next-Screens.md`の依頼書・新タイトル・部屋操作・新ランク恩恵は、この4画面の実装とは別の残作業。

## 検証

最初の全体実行は97件中89件成功・8件失敗。旧UIの文言・配置・メニュー階層を前提にする検証を承認デザインの仕様へ更新し、画面遷移の待ち時間と年間評価の試遊方針も修正した。保存互換と途中終了の判定を1件追加し、**再実行は98/98成功**（681.68秒、`Artifacts/company-next2-all-20260929.json`）。3タイプ各5年度・計180か月の実画面操作もこの全体実行に含む。

全体実行後の目視でチュートリアルの通常ひなたが背後に残っていたため、ガイド中は通常ひなたの親ごと隠し、飛ばすと戻すよう修正した。年間評価の承認された70px移動と合わせ、**年間評価・6段階ガイド・スキップ復帰の対象3件が各1/1成功**。70px移動と二重表示解消を撮り直した画像で確認した。全体98件の結果と、その後の対象確認は区別して記録する。

Unity不要のルール検証：旧版、新試作、3タイプの450年度、3視点×3深度の900年度が成功。新試作の再検証も成功。コンパイルは本体・Editor・Testsの3アセンブリが成功、警告0件。自動試遊は実在の人間・専門家による楽しさや学習効果の評価ではない。

Windows試遊版も更新。Editorログで`Build Finished, Result: Success`とビルダーの成功を確認し、更新されたDLLを含む実行版でBGM2曲の切替・再生位置の進行と12か月完走がPASSED（`Artifacts/company-player-next2-20260929.log`）。利用者のセーブは読み書きせず、音を消した自動検証なので、音色やループの聴覚評価とは別。終了時には従来のComputeBuffer解放警告が残る。CompanyYearの編集用プレビューも新UIで保存し、旧版は変更していない。

編集プレビューの保存後にも、共通ウィンドウ／4種類のボタンの対象1件を再実行して1/1成功（`Artifacts/company-next2-kit-final-20260929.json`）。ソース・文書の差分には空白エラーなし。Unityが書き出したシーンの空の名前などの末尾空白は、シーンを手で書き換えない方針のため、そのまま保持した。
