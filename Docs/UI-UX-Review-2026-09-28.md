対象：9/28 15:30撮影の`Artifacts/CompanyOps/`（1600×900・1920×1080）と`Artifacts/OfficeReview/`。演出・音はコードも確認。
人間の試遊ではない。方針面は`UI-UX-Research-2026-09-28.md`（Codex）と同意見なので、ここでは**画面で確認できた具体的な欠陥**と、演出・音・キャラを扱う。

## 総評

- **良い**：色の役割が固定され、上部バーは項目名＋数値＋単位＋ゲージが揃って読みやすい。書体の役割分担、3案を同じ位置・同じ単位で並べる対応比較、予測と確定を区別する誠実さ。ドット絵のオフィスは世界観の核として強い。
- **弱い**：見た目が「ゲーム」より「業務ダッシュボード」。暗い平面カードに文章が並び、主役のオフィスはラベルで4割近く隠れ、ひなたは白い箱に閉じ込められている。参考画像の「キャラが前に出て、色で場面が分かる」方向から離れている。

## レイアウト

- 計画画面にテキストの塊が50以上、「>」付きの押せる箱が10以上ある。押せる箱と表示だけの箱が同じ見た目。
- 「高いほど良い／低いほど良い」の常設補助文は、2か月目以降は不要な情報になる。初月だけ出すか、ツールチップにする。
- 疲労カードの赤い帯が平常時（21/100）から常に点灯している。危険色は閾値を超えたときだけにする。
- 左の月カレンダーで6・9・12・3月に赤い下線があるが、凡例がない。
- **年間評価（08）が一番地味な画面**。大きな余白に文字だけで、ランクの演出・月ごとの推移・ひなたの反応がない。一年の締めくくりを最大の見せ場にする。
- 旧版（OfficeReview/02）：右パネルの下半分と中央下の実績欄が空で、画面の約3割が空き。吹き出しがベージュ＋ピンクで、他の暗いUIと様式が別。

## ひなた

- 明るい白い箱は暗いUIの中で最も目立つが、中身は「一緒に考えよう。」「なるほど！」など情報の薄い一言が多い。視線を一番集める場所の情報が一番少ない。
- 表情が1枚のため、ランサムウェアの場面でもガッツポーズの笑顔になり、場面と感情が合わない。原画が揃うまでは、絵を偽らずにできる**動き**で補うのが安く効く（通常時のゆっくりした上下、成功で小さく跳ねる、警告で身を引く・細かく震える）。
- 参考画像の方向にするなら、箱から出してオフィスの端に大きく重ね、吹き出しを付ける。タイトル画面はすでにこの形で、全画面の中で一番良い。

## 演出

- 実装済み：浮遊する増減値、ゲージの変化、パンチ、フラッシュ、設備購入時のオフィスの印の反応、結果枠の色分け。
- 数値の変化は伝わるが、**世界（オフィス）が変わらない**。設備を入れてもサーバー室の絵は同じで、社員は静止し、事件中も平常時と同じ絵のまま。変わるのはラベルの文字だけ。
- 提案（効果が大きく実装が軽い順）：
  1. 月替わりに0.5秒の暗転と「5月」の大きな表示
  2. 年度クリアでランクの判子を押す演出と、ひなたの専用反応
  3. 事件中は該当する部屋に赤い印を付け、他の部屋を少し暗くする
  4. 設備のLvに応じてオフィスに小物が増える（ラックやランプの点灯）

## 音

- SEは10種すべてサイン波の合成音（`OpsSoundDesign`）。役割分け（被害は低音、成長は上向き）は正しいが、音色は電子音のビープで、「気持ちいい」手応えにはならない。
- **BGMが無いことが最大の欠落**。無音では、演出を足しても体験が寂しい。
- 提案：実素材のSEに差し替える（ボタン、購入のレジ音、警告、成功のジングル。CC0のKenneyなど）。BGMは「平常」「事件」の2曲だけでも効果が大きい。フリー素材は、クレジット表記・再配布・Steam販売の可否をライセンスで確認してから入れる。

## 推奨する順番

1. 不具合1〜6（小さく、確実に良くなる）
2. BGM 2曲とSEの差し替え（体験への効果が最大で、コードの変更は少ない）
3. 月替わり・年度クリアの演出と、ひなたの動き
4. 情報量の整理（Codex調査の「3画面」案）。試遊の感想を見てから着手する
