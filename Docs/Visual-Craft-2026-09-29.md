# 凝った表現の技法集（Claude、2026-09-29）

加藤さんの方針：**細部で妥協しない。手の込んだ絵・デザイン・凝り要素を増やす。**
動き・時間の技法（ヒットストップ、数え上げなど）は`Docs/Game-Feel-Research-2026-09-29.md`。ここは**質感・装飾・画面づくり**を中心に、どこへ使うかまで決める。
見本：`Docs/Mockups/proto-b-incident.html`（下の★を実装済み。ブラウザで開くと見られる）。

## 1. 質感（素材そのものの手触り）

| 技法 | 中身 | 使う場所 | Unityでの作り方 |
|---|---|---|---|
| ガラス玉 | 中心が明るい放射グラデーション＋白い縁＋外の色の縁＋影。下が透ける | 困りごとの泡、図鑑の宝石、ランクの玉 | UI画像（`Assets/Art/UI/Bubbles/`を作った方法） |
| ★上からの光沢 | パネル・ボタンの上4割に白の薄いグラデーション | すべてのパネルとボタン | 共通の光沢画像を重ねる（UIキットの`button-shine`を全パネルへ） |
| 箔押し（光が走る） | 斜めの白い帯が、ランク文字や勲章の上を一定間隔で横切る | ランク、勲章、レアの泡、SS評価 | マスク＋横に流れる帯（既存の`Shine`を流用） |
| 縫い目（ツギハギ） | 白い破線の縁取り。作品名 PatchWork のモチーフ | 札・カード・吹き出しの内側 | 破線の9スライス画像 |
| 紙・布の地紋 | ごく薄い布目や網点を面に重ねる（不透明度3〜6%） | 月報、依頼書、年間評価の紙面 | 繰り返し模様のUI画像 |
| 走査線と発光 | 横線を細かく重ね、中央を少し明るく | ログ・監視・サーバー室の画面（試作E） | 繰り返し模様＋放射グラデーション |

## 2. 装飾・構図

| 技法 | 中身 | 使う場所 |
|---|---|---|
| 斜めの帯 | 端を斜めに切った単色の帯。動きと勢い | 見出し、副題、カットインの帯（Polish-4の14） |
| 2段の文字の縁取り | 白の縁＋薄い色の縁で、背景から浮かせる | タイトル、ランク、大きな数字（Polish-4の15） |
| 集中線・スピード線 | 中心へ向かう線 | 発動カットイン、山場の突破 |
| 奥行きの層（視差） | 背景・人物・手前の花びらを別々の速さで動かす | タイトルの一枚絵、キャラ選び、主役絵 |
| 被写界深度の切り替え | 背景をぼかし、主役を切り替えるときに焦点も移す | 主役絵の差し込み、会話の話者の切り替え |
| 場面の色味 | 画面全体に薄い色を重ねる（事件＝赤、夜＝紺、成功＝暖色） | 事件、夜間・休日、季節 |

## 3. 反応（触ったときの返り）★は見本に実装済み

| 技法 | 中身 | 使う場所 |
|---|---|---|
| ★広がりの線 | 感染が隣へ移る瞬間、光る赤い線が一瞬走る＋小さな電子音 | 封じ込め。脅威が「動いている」と見せる |
| ★破片と光の輪 | 切り離した瞬間、白い輪が広がり、破片が10片飛ぶ | 封じ込め、泡を弾く、メールを見破る |
| ★ヒットストップ | 当たりの瞬間だけ0.07秒止め、対象を1.18倍に | 感染の切り離し、偽の承認を弾く |
| ★危険の脈動 | 残り6秒で画面の縁が赤く脈打ち、心音が鳴る（3秒で速く） | すべての時間制限つきミニゲーム |
| ★数え上げ＋判子 | 点数が音つきで数え上がり、止まった瞬間にランクが判子のように押される（箔の光が走る） | ミニゲームの結果、月報、年間評価 |
| ★漂う光の粒と流れる格子 | 背景にゆっくり上る粒と、流れる網目 | 事件・ネットワーク系の画面 |
| 押した感触 | ボタンが3px沈み、影が縮む。離すと少し跳ねる | すべてのボタン（UIキットにあり、全画面で統一する） |
| 音程の階段 | 連続成功のたびに半音ずつ上がる | ミニゲーム全般（試作で実装済み） |

## 4. 絵の見せ方

| 技法 | 中身 |
|---|---|
| 一枚絵のゆっくりした寄り（実装済み） | タイトルで20秒周期 |
| 主役絵の差し込み | 山場の突破・ランクSS・キャラの見せ場で、主役絵を斜めの帯の中に差し込む（ソシャゲのカットイン） |
| まばたき・呼吸 | 一枚絵にも目の差分を重ね、胸元をわずかに伸縮 |
| 表情の切り替えの間 | 表情を変える直前に0.1秒だけ目を閉じる、驚きは一瞬大きく |

## 5. 進め方

1. Polish-4（細部の16件）を先に直す。直す前後をモックと並べて確かめる（`Tools/Compare-Mock.py`）。
2. ミニゲームを実装するときは、この表の★をそのまま入れる（Next-5の手本は、★を入れた後の`proto-b-incident.html`）。
3. 質感の素材は`Assets/Art/UI/Craft/`に用意済み（`stitch-frame`＝縫い目の9スライス・枠幅32、`gloss-top`＝上からの光沢、`foil-sheen`＝箔押しの光の帯、`ribbon-slant`＝右端を斜めに切った帯・左は9スライス、`paper-grain`＝紙の地紋・繰り返し、`halftone`＝網点・繰り返し、`scanline`＝走査線・繰り返し、`speed-lines`＝集中線）。すべて白で描いてあるので、Unityで色を付ける。GPTが組み込む。
