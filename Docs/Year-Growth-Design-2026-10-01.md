# 年ごとに会社が育つ — 開幕演出と、2・3年目で本当に増えるもの（Claude、2026-10-01）

加藤さんの案（10/1）：2年目・3年目に入るとき、会社の規模が大きくなる、新たな設備・新たなレベル、まだ見ぬ強敵、心強くなった味方がそれを迎え撃つ——心躍る演出と、そう感じられる2・3年目にしたい。
方針：**演出で見せたものは、すべて遊びの中身として実際に増える**（見せるだけで中身が同じだと、2回目から白ける）。数値は試算してから決める。

## 2. 2・3年目で本当に増えるもの

| | 2年目「広がる会社」 | 3年目「狙われる会社」 |
|---|---|---|
| 会社の規模 | 新しい拠点。地図に「拠点」の部屋が増え、困りごとの泡が出る場所も増える。社員24→38人、端末30→56台（表示） | 取引先とデータをつなぐ部屋が増える。社員38→52人、端末56→80台 |
| 新しい設備 | ゼロトラスト接続（前提：多要素認証）、端末の検知と対応＝EDR（前提：監視） | 脅威情報の共有（業界の情報共有に参加。前提：監視）、事件対応の体制＝CSIRT（前提：手順） |
| 強敵（山場の月） | 6月 委託先から忍び寄る影、9月 AIで化ける詐欺師、12月 暗号化の群れ、3月 抽選 | 6月・9月・12月の強敵、3月 3年目の総決算（`y3-final`） |
| 仲間 | エンジニアさんが週2日常駐：月1回「調査を頼む」（工数0、把握+1）。かのんさん：山場の月は臨時予算が通りやすい | 後輩が4人目の社員として入る（Lv1から育てる）。ひなたの支えで、後輩の経験が少し増えやすい |
| 成長目標 | 拠点まで見える／入口を重ねて守る／誰が休んでも回る（`Docs/Story-Years-Content-2026-10-01.md`） | 戻せることを証明した／気づいて止める／相談が文化になった |

- 新しい設備は、その年の強敵に効く（ゼロトラスト→委託先・在宅、EDR→暗号化の群れ、脅威情報→標的型・侵害の主張、CSIRT→総決算の停止）。「この敵には、この備え」が分かる。
- 強敵は図鑑に「強敵」の欄で残る（日記帳と同じく、挑戦をまたいで集める）。
